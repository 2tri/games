# 「디지몬 금」 기획 (가제, 비공식 팬 게임)

『포켓몬스터 금』(게임보이 컬러) 감성의 도트 RPG. 포켓몬 요소는 전부 빼고 디지몬과 『디지몬 어드벤처』 인물로만 채운다.
참고작: 하트골드 개조판 「포켓몬스터 디지몬골드」. 단, 그 게임의 파일·그림은 쓰지 않고 모두 새로 그린다.

## 이름 규칙
- **공식 이름만 쓴다. 지어낸 이름 금지.**
- 디지몬: 원작 이름의 한국어 표기 (예: 아구몬, 가부몬, 쿠와가몬)
- 사람: 한국 방영판 이름 (예: 신태일, 매튜)
- 표기가 확실하지 않은 이름은 `(확인 필요)`를 붙이고, 확인하기 전까지는 게임에 넣지 않는다.

## 화면·조작
- 160×144 화면을 폰 폭에 맞춰 키움. 아래에 십자키·A·B·START·SELECT (`ring/`과 같은 방식)
- 한글 글꼴: 갈무리 9 (OFL)

## 도트 규격 (금판 기준)
| 쓰임 | 크기 | 색 |
|---|---|---|
| 전투 앞모습 | 56×56 칸 (성장기는 40×40으로 그려 바닥에 맞춤) | 흰·검 + 2색. 대표 무늬가 있으면 1색 더 (그레이몬의 파란 줄무늬) |
| 전투 뒷모습 | 48×48 | 같음 |
| 필드 인물 | 16×16 | 외곽선 + 4~5색 |
| 지도 칸 | 16×16 | 칸마다 2~4색 |
- 전투 배경은 금판처럼 흰 바탕에 받침 원을 그리지 않는다.

## 포켓몬 금 → 디지몬 금 대응
| 포켓몬 금 | 디지몬 금 |
|---|---|
| 주인공 금 | 신태일 + 파트너 아구몬 |
| 라이벌 실버 | 매튜 + 가부몬 |
| 공박사 | 겐나이 |
| 배지 8개 | 문장 8개: 용기·우정·사랑·지식·순수·성실·희망·빛 |
| 타입 상성 | 속성 상성: 백신 → 바이러스 → 데이터 → 백신 |
| 포켓몬 진화 | 디지몬 진화 (성장기 → 성숙기 → 완전체 → 궁극체) |
| 사천왕 / 챔피언 | 다크마스터즈 넷 / 아포카리몬 |

## 이야기 흐름 (애니 1부 기준)
| 장 | 무대 | 우두머리 |
|---|---|---|
| 1 | 파일섬 (해변 전화박스 → 정글) | 쿠와가몬, 쉘몬 → 데블몬 (표기 확인 필요: 원작 「데비몬」) |
| 2 | 서버 대륙 | 에테몬 |
| 3 | 현실 세계 | 반데몬 (한국 방영판 이름 확인 필요) |
| 4 | 스파이럴 마운틴 | 다크마스터즈 넷 |
| 5 | 마지막 싸움 | 아포카리몬 |

## 결정할 것 (사용자)
1. 디지몬 이름: 원작 이름(가부몬·테일몬)으로 갈지, 한국 방영판 이름(파피몬·가트몬)으로 갈지
2. 진화: 애니처럼 전투 중에만 진화했다가 끝나면 돌아갈지, 포켓몬처럼 한 번 진화하면 그대로일지
3. 포획: 디지몬골드처럼 야생 디지몬을 잡을지, 선택받은 아이들의 파트너만으로 싸울지
