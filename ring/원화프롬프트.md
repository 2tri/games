# 원화 프롬프트 (이미지 생성 AI용) — 「반지 원정」

## ★ 도트 그림을 바로 받는 프롬프트 (추천) → `tools/snap.py`로 칸 맞춤
이미지 AI에게 처음부터 '도트 그림'으로 받으면, snap.py가 칸 크기를 찾아 진짜 56칸 4색 도트로 정리한다
(시험: 7배로 키워 JPEG로 망가뜨린 도트를 99.5% 복원).
```
[캐릭터 설명], Pokemon Gold and Silver Game Boy battle sprite, pixel art, 56x56 pixels,
only 4 shades of gray (white, light gray, dark gray, black), 1 pixel black outline,
3/4 view facing left, dynamic pose, plain white background, single character, no text
```
예) 골룸: `Gollum crouching on a rock, hunched back, huge round eyes, few strands of hair, bony fingers, grinning` + 위 문장


원화를 받아 `tools/pixelize.py`로 게임보이 4색 도트(적 56×56 / 40×40, 인물 32×32)로 바꾼 뒤 손으로 다듬는다.

## 변환이 잘 되는 원화 조건
- 한 장에 **한 인물만**, **배경은 완전한 흰색**(풍경·바닥 그림자 없이)
- **전신**, 화면을 꽉 채우게(위아래 여백 적게). 몸이 길쭉하면 작아지니 **머리 큰 3~4등신**이 좋다
- **굵은 검은 선 + 흑백 명암**(회색 몇 단계). 잔 빗금·질감은 적을수록 좋다
- 정면 차렷 말고 **3/4 각도, 동작 있는 자세**
- 영화 장면을 그대로 옮기거나 배우 얼굴을 닮게 하지 않는다(제작확인서)

## 공통 문장 (모든 프롬프트 뒤에 붙임)
```
single character, full body, plain pure white background, no scenery, no text, no frame,
bold clean black ink line art with flat grayscale cel shading, high contrast,
3/4 view, dynamic action pose, chunky readable silhouette, 3-4 heads tall chibi proportions,
retro handheld RPG battle sprite concept, original character design
```

```
a towering ancient demon of shadow and flame, massive curved horns, huge ragged bat-like wings made of smoke,

+ 공통 문장
```

## 2. 골룸 (적)
```
an emaciated pale cave creature, huge round shining eyes, only a few thin strands of hair, large pointed ears,

+ 공통 문장
```

## 3. 간달프 (주인공, 앞모습 + 뒷모습 두 장)
앞모습:
```
an old wandering wizard with a very long grey beard and bushy eyebrows, tall pointed grey hat with a wide drooping brim,
long grey robes and a silver scarf, raising a gnarled wooden staff high, a sword in the other hand, determined stare
+ 공통 문장
```
뒷모습(전투용):
```
the same old wizard seen from behind, over-the-shoulder back view, grey pointed hat and grey robes,
gnarled wooden staff raised, facing away from the viewer toward an enemy
+ 공통 문장
```

## 같은 방식으로 이어서 만들 목록
- 주인공 뒷모습: 프로도와 샘(둘이 나란히), 아라곤, 레골라스, 김리
- 적: 검은 기사, 사루만, 우루크하이, 동굴 트롤, 쉴로브, 마술사왕, 무덤 악령, 버드나무 영감, 호수의 감시자
- 인물: 갈라드리엘, 보로미르, 빌보, 엘론드, 아르웬, 세오덴, 에오윈, 파라미르
