# 「반지 원정」 인수인계 (다음 세션·다른 계정용)

**최신 상태(2026-10-01)**: 웹판(`ring/index.html`, https://2tri.github.io/games/ring/)으로 **전편(1~8장 + 덧붙이는 장 「샤이어 소탕」·회색 항구 엔딩) 플레이 가능**, 마지막 step 41. 샤키(`sharkey` 48×56)·백색의 간달프(`gandalfw_front` 64×64, 얼굴 손보정)·에오윈(`eowyn_front` 56×64, 방패 면 밝힘)·톰 봄바딜(`tom_front`)·프로도를 업은 샘(`samfrodo_front`, 바닥 경사 지움) 반영. 남은 요청: 사우론의 눈·절대반지(선택). ingest.py가 8의 배수 채움까지 처리. 최종 목표는 **Delta에서 여는 GBC 롬** — 저장소 루트 `GBC_롬_가이드.md` 참고, GBC 전투 시험판 `ring/rom/ring.gbc`(조작되는 6연전, 엔진 `ring/rom/src/`). 이야기 전체(1~8장) 롬에 들어감. **걷는 화면(필드) 추가**: `rom/field.py`(글자 격자 지도·사람·표지판·물건·사건 자리·야생 목록) + `rom/src/fieldrt.c`. 지금 샤이어(1~2단계)만 걷는 화면, 3단계부터는 이야기 장면 차례 진행 → 지역별 지도를 하나씩 추가할 차례. 타일은 무료 CC0 임시, 제미나이 그림(`그림프롬프트.md`) 오면 교체.

## 역할 분담 (사용자 확정)
- 그림: 사용자가 이미지 AI로 만들어 전달 → 프롬프트는 Claude가 캐릭터별로 한 블록씩 채팅에 줌(폰에서 .md가 안 열림)
- 그 밖의 전부(도트 정리·게임 넣기·운영·스토리·마감): Claude

## 파일
- `index.html` 게임 전부(그리기·입력·전투·이야기 CH1 배열·저장 localStorage `ring-save-v1`)
- `ai/sprites.js` 모든 그림(4단계 배열), `ai/*_ai.png` 원본, `ai/*.npy`
- `tools/snap.py` `tools/ingest.py` 그림 정리, `tools/grid.py` 참고 사진 격자
- `기획.md` 이야기 구성(영화 3부작 + [원작]/[확장판] 대목), `제작확인서.md`
- `ref/목록.md` 참고 사진 목록(이미지 파일은 저장소에 없음, `pick.py`로 다시 받기)

## 그림 현황
주인공 앞·뒤: 프로도와 샘(한 캐릭터), 아라곤, 레골라스, 김리, 간달프
적: 개·버드나무·무덤 악령·검은 기사·골룸·감시자·고블린·동굴 트롤·발로그·우루크하이·와르그·크레바인·사루만·쉴로브·마술사왕·날짐승 나즈굴·사우론의 입·무마킬·모르도르 오크
인물: 빌보·엘론드·아르웬·보로미르·메리와 피핀·갈라드리엘·파라미르
아직 없음(필요 시 요청): 백색의 간달프, 세오덴, 에오윈, 망자의 왕, 샤키(사루만 거지 모습), 버터버, 톰 봄바딜

## 시험 방법
`python3 -m http.server` 후 Playwright로 저장 상태를 localStorage에 넣고 'z' 연타 자동 진행(스크립트 예: 세션 기록의 mash*.js). 장 단위로 오류·막힘 확인.
