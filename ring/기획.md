# 「반지 원정」 기획 (비공식 팬 게임)

원작 『반지의 제왕』의 흐름을 따라가는 게임보이풍 도트 RPG. 대사와 그림은 모두 새로 만든다.

## 화면·조작
- 게임 화면 160×144(게임보이 컬러 해상도)를 폰 폭에 맞춰 확대. 아래에 십자키·A·B·START·SELECT.
- 한글은 갈무리 도트 글꼴(OFL).

## 이야기 방향
- **뼈대는 영화 3부작**(반지 원정대 → 두 개의 탑 → 왕의 귀환)의 흐름과 장면 순서를 따른다.
- 영화가 건너뛰거나 줄인 **빈 곳은 원작 대목**으로 채워, 영화를 본 사람에게는 익숙하고 원작 팬에게는 "이것도 들어갔네" 싶게 만든다.
- 대사는 영화·원작 문장을 그대로 쓰지 않고 새로 쓴다. 장면은 흐름만 따르고 연출·구도는 게임보이식으로 새로 만든다.
- 표에서 **[원작]** 표시가 영화(극장판)에 없거나 크게 줄었던 원작 대목이다. 확장판에 일부 들어간 대목이 있을 수 있어, 제작 때 장면별로 다시 확인한다.

## 인물 선택
- 시작할 때 **프로도와 샘 · 아라곤 · 레골라스 · 김리 · 간달프** 중 하나를 고른다.
- **프로도와 샘은 한 캐릭터**다. 따로 고르거나 혼자 플레이하지 않고, 그림(앞·뒤 모습)도 둘이 나란히 붙은 한 장(44×32)으로 쓴다.
- 고른 인물마다 **도입부가 다르고**, 3장 깊은골에서 모두 만나 원정대가 된다. 원정대가 갈라진 뒤(6장~)에는 고른 인물이 속한 갈래를 걷는다.

| 고른 인물 | 도입부 (1~2장 자리) | 6~8장 갈래 |
|---|---|---|
| 프로도와 샘 | 샤이어 출발 → 브리 → 바람마루 → 브루이넨 여울 | 반지 갈래 |
| 아라곤 | 브리 「달리는 조랑말」에서 호빗들을 지켜보다 합류 → 바람마루 | 왕의 갈래 |
| 레골라스 | 어둠숲: 골룸이 요정들의 감시를 뚫고 달아난 일[원작] → 깊은골로 소식을 전하러 | 왕의 갈래 |
| 김리 | 외로운 산: 모르도르의 사자가 난쟁이들에게 반지를 캐묻고 감[원작] → 아버지 글로인과 깊은골로 | 왕의 갈래 |
| 간달프 | 미나스 티리스 서고에서 반지의 정체 확인 → 오르상크에서 사루만에게 갇힘 → 큰독수리 타고 탈출 | 모리아 이후 → 백색의 간달프로 왕의 갈래 |

- 메리·피핀·보로미르·파라미르·에오윈 등은 동료(파티)나 이벤트 인물로 나온다. 선택 인물로는 늘리지 않는다.

## 줄거리 (8장 + 덧붙이는 장)
### 1부 「반지 원정대」
| 장 | 무대 | 영화 흐름 | 사이에 넣는 원작 대목 | 우두머리 |
|---|---|---|---|---|
| 1 | 샤이어 → 노루말 나루 | 빌보의 생일잔치, 반지를 물려받음, 간달프의 경고, 샘과 출발, 농부 매곳 밭에서 메리·피핀 합류, 검은 기사 피해 숨기 | **묵은숲·버드나무 영감, 톰 봄바딜의 집, 무덤 언덕**[원작] — 무덤 악령을 물리치고 서쪽나라 단검을 얻음 | 무덤 악령 |
| 2 | 브리 → 바람마루 → 브루이넨 여울 | 달리는 조랑말, 성큼걸이, 바람마루 습격·프로도 부상, 여울에서 검은 기사를 물로 쓸어냄 | 여울로 가는 트롤숲 — 빌보 옛 모험 때 돌이 된 트롤들[원작] | 검은 기사 다섯 |
| 3 | 깊은골 → 카라드라스 | 엘론드의 회의, 원정대 결성, 빌보가 스팅·미스릴 갑옷을 줌, 눈보라 고개 | 원정대 떠나기 전 정찰대가 돌아오는 두 달[원작] — 깊은골 쉼터·상점 구간 | — |
| 4 | 모리아 | 호수의 감시자, 발린의 무덤, 동굴 트롤, 크하자드둠 다리에서 간달프 추락 | 마자르불 방 문에서 간달프가 어둠의 존재와 문 봉인을 겨루는 대목[원작] | 동굴 트롤 |
| 5 | 로스로리엔 → 대강 → 아몬 헨 | 갈라드리엘의 거울·선물(요정 망토·렘바스·빛의 병), 보로미르의 마지막 싸움, 원정대가 갈라짐 | 할디르가 이끄는 숲길 — 김리 눈가리개 다툼과 화해, 케린 암로스 언덕[원작] | 우루크하이 대장 |

### 2부 「두 개의 탑」 — 두 갈래
| 장 | 반지 갈래 (프로도와 샘) | 왕의 갈래 (아라곤·레골라스·김리·간달프) | 우두머리 |
|---|---|---|---|
| 6 | 에민 무일에서 골룸을 길들임 → 죽음늪 → 검은 문 → 이실리엔에서 파라미르에게 붙잡혀 오스길리아스까지 | 우루크하이 추격 → 팡고른에서 백색의 간달프 → 에도라스 → 헬름협곡 방어전 / 메리·피핀의 엔트 회의·아이센가드 공격은 막간 장면 | 나즈굴의 날짐승 / 연속 파도 |
| | 사이 원작 대목: 헨네스 안눈 동굴에서 파라미르가 들려주는 곤도르 옛이야기[원작] | 사이 원작 대목: 아이센가드 폐허에서 사루만과의 담판, 팔란티르[원작·영화 극장판에 없음] | |

### 3부 「왕의 귀환」
| 장 | 반지 갈래 | 왕의 갈래 | 우두머리 |
|---|---|---|---|
| 7 | 미나스 모르굴 → 키리스 웅골 계단 → 쉴로브의 굴 → 키리스 웅골 탑에서 샘이 프로도 구출 | 미나스 티리스 공성(간달프) → 망자의 길 → 펠렌노르 평원 → 검은 문 앞 마지막 싸움 | 쉴로브 / 앙그마르의 마술사왕 |
| | 사이 원작 대목: 반지를 맡은 샘이 **반지의 유혹(온 땅을 정원으로 만드는 환상)을 이겨내는** 대목[원작] | 사이 원작 대목: 드루아단 숲의 야인들이 길 안내[원작] | |
| 8 | 운명의 산 — 마지막 오르막, 골룸과의 마지막 | 검은 문 앞에서 시간을 버는 싸움 | 최종 |

### 덧붙이는 장 (엔딩 뒤)
- **샤이어 소탕**[원작] — 영화에 없는 원작의 결말. 돌아온 호빗들이 망가진 샤이어를 되찾고 「샤키」를 몰아낸다. 클리어 뒤 보너스 장.

## 장비 흐름 (영화 + 원작)
- 프로도: 지팡이 → 무덤 언덕의 서쪽나라 단검[원작] → 깊은골에서 스팅·미스릴 갑옷 → 로리엔 요정 망토·빛의 병
- 스팅은 오크가 가까우면 푸르게 빛난다(전투 전 경고 연출).

## 전투 (포켓몬식 화면)
- 위에 적 앞모습, 아래에 내 인물 뒷모습, 맨 아래 대사창. 메뉴: 싸운다 / 가방 / 동료 / 도망.
- 파티 최대 4명. 한 명씩 나가 싸우고 「동료」로 교체.
- 인물마다 기술 4개, 레벨업, 상태 변화(화상·약화·은신 등).
- 프로도 전용 「반지 끼기」: 모습을 감춰 공격을 피하지만 쓸수록 「그림자」가 쌓인다.
- 가방: 렘바스(회복), 약초 등.

## 필드
- 16×16 타일 지도, 4방향 걷기, 풀숲·어둠 속에서 적 조우, 마을 사람과 대화, 상자.

## 도트 규격 (확정)
- **게임보이 4단계 무채색**(흰·밝은회·어두운회·검정). 바깥선과 부위 사이 선은 검정, 부위마다 밑색 + 그늘 한 단계.
- 2등신(머리가 큰) 도트, 각진 덩어리.

| 쓰임 | 크기 |
|---|---|
| 인물 앞·뒤 모습 | 32×32 (프로도와 샘은 44×32 한 장) |
| 전투 뒷모습 | 32×32를 2배(초대 포켓몬 방식) |
| 필드 걷기 | 16×16, 4방향 × 2동작 |
| 적 | 40×40, 우두머리 56×56 (1배) |
- 인물 외형은 **영화 분위기**(차림새·무기·머리 모양)를 따른다. 배우 얼굴을 닮게 그리거나 영화 장면 구도를 그대로 옮기지는 않는다.

## 만드는 순서
1. 게임기 화면·조작, 제목, 인물 선택, 1장(샤이어 → 무덤 언덕), 저장
2. 2장 브리·바람마루·여울, 3장 깊은골(원정대 결성), 나머지 인물 도입부
3. 4장 모리아
4. 5장 로스로리엔·대강·아몬 헨
5. 6장 두 갈래(반지 갈래 / 왕의 갈래)
6. 7장 키리스 웅골 / 펠렌노르, 8장 운명의 산, 엔딩
7. 덧붙이는 장 「샤이어 소탕」
- 음악은 나중에(사용자가 구한 무료 음원 또는 새로 만든 8비트 곡).
