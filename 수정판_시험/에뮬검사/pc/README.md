# PC(Windows)용 에뮬 시험 도구 (2026-10-26)

작업 폴더에 `rom.nds`(최신 롬 복사본)와 `hdr.json`(hdr.py 결과)을 두고 그 폴더에서 실행. py-desmume(`python -m pip install py-desmume`)로 Windows PC에서 바로 돌아감. 롬 경로는 인자로 줌. 시험 롬은 배포 롬이 아님.

- `newgame.py <롬> <폴더> 400` — 전원부터 새 게임 → 2층 방(지도 64) 상태 `end.dst`.
- `hdr.py` — RAM 에서 지도 머리말 표(24바이트×540)를 읽어 `hdr.json` 생성. 필드: raw[5]=matrix, [6]=script, [7]=레벨 스크립트, [8]=글, [11]=이벤트.
- `mktest.py <롬> <출력> "<명령>"` — 방(스크립트 846) 진입점을 시험 명령으로 바꾼 시험 롬. 방 PC 앞(U1 u A)에서 실행.
  명령: `mon:종,레벨` `item:번호,개수` `var:16진,값` `flag:16진` `heal` `warp:지도,x,y,방향(0위1아래2왼3오른)` `raw:16진`
- `drive.py <롬> <in.dst> <out.dst> <폴더> "<토큰>"` — 걷기(U3 L1…), 방향만(u d l r), A/B/X, `W프레임`, `T x,y`(아래 화면 좌표 0~191), `AUTO최대`(대화·전투 자동), `TOMENU`(전투 메뉴까지), `M주소=값`(u32), `SHOT이름`.
- `coll.py <지도> x0 x1 y0 y1` — 충돌표 출력(`#` 막힘). 땅 자료 머리 = 0x14 + (0x12 의 u16).
- `ev.py <지도…>` — 지도 이벤트(사람·워프·칸·표지판). `findwild.py <종…>` — 고정 전투/선물 스크립트 찾기.
- 현재 위치 RAM(이 빌드): 0x0227DE78 = 지도(지도 바뀔 때만 갱신). 게임 시계 0x021D1A58/0x021D1A74.
- 요일 조건(돌핀몬 금, 켄터스몬 목·일)은 RAM 시계로 안 바뀜 → 시험 롬에서 비교 값을 오늘 요일로 바꿔 시험.
