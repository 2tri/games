# 에뮬레이터 자동 시험 도구 (2026-10-20)

py-desmume(`SDL_VIDEODRIVER=dummy SDL_AUDIODRIVER=dummy`)로 롬을 돌려 **내 파티에 원하는 디지몬·레벨·기술을 넣고 전투**를 시켜 보는 도구.

- `pkm.py` — 4세대 포켓몬 파티 자료(236바이트) 풀기·쓰기(블록 섞임·체크섬·능력치·경험치). 파티 RAM 을 고쳐도 전투가 멈추지 않게 체크섬·능력치까지 다시 씀.
- `mkenemy.py <롬> <출력> <종> <레벨> <기술> [one]` — 소라(트레이너 20) 파티를 지정 종·기술로 바꾸고 연구소 진입점을 「소라와 전투」로 바꾼 시험용 롬 사본을 만듦(배포 롬 아님).
- `lab2.py <롬> <폴더> <종> <레벨> <기술,...>` — 연구소 저장 상태(`ag4.dst`: 스타팅 받은 직후)에서 내 첫 마리를 바꾸고 전투 → 「싸운다」 → 기술을 하나씩 써 프레임 시트·활동량(log.json) 저장. 기술 메뉴 화면(menu.png)에서 기술 이름·타입·PP 를 볼 수 있음.
- `evo.py <롬> <폴더> <출발> <방법> <값> <도착>` — 진화 레벨 직전(경험치 1 모자람)까지 올린 마리로 전투에서 이겨 진화 뒤 파티 종 번호를 읽음. `HOUR=22`(밤)·`HOUR=12`(낮)로 게임 시계 RAM 을 고쳐 낮/밤 진화를 시험. `LV`·`HOLD` 로 레벨·지닌 물건 덮어쓰기.
- `anim.py`, `meas_one.py`, `shot_one.py`, `walk.py` — 전투 화면 캡처, 앞모습 위치 측정(ground_base.json 만든 도구).
- 필요한 저장 상태 `ag4.dst`(용량이 커서 저장소에는 없음)는 `chain.sh`(새 게임 → 연구소 → 스타팅 아구몬) 뒤 「왼쪽 1칸」 간 상태로 만든 것.

파티 RAM 주소(이 상태 기준): 0x0227cce8 · 0x022bc958(같은 마리 두 곳 — 둘 다 써야 함). 게임 시계 RAM: 0x021d1a58·0x021d1a74 (년 월 일 요일 시 분 초, 4바이트씩).

## 추가 도구 (2026-10-20 오후)
- `mktrainer.py <롬> <출력> <트레이너 번호>` + `trn.py <롬> <폴더> <번호>` — 트레이너 전투 도입 화면·첫 마리·메뉴 도착 확인(737명 전수 시험에 사용). `dbl.py` — 더블 배틀 시험.
- `mkscript.py <롬> <출력> "<명령 바이트 16진>"` — 연구소 진입점을 임의 스크립트 명령으로 덮어쓴 시험 롬. 예: `"6001 00 0000 0000"` = 요약 화면(명령 352). 이 방법으로 X 메뉴 터치가 안 열리는 문제를 우회.
- `요약화면.py <mkscript 롬> <폴더> all 50 [--shard i/n]` — 188종 요약 화면(메모·능력치·기술) 촬영.
- `글_화면검사.py <최종 롬> <ag4.dst 폴더> <결과 폴더> [--min 18] [--shard i/n] [--only 219:135,...] [--labrom 롬]` — 바뀐 대사를 실제 대화창에 띄워 잘림 확인.
- 주의: `ag4.dst` 는 `evo.py`·`lab2.py` 가 도구 폴더에서 찾음(저장소에 없음) — 필요하면 심볼릭 링크를 만들고 커밋하지 말 것.
- `dbl.py` — 더블 배틀 시험(내 파티 2마리 필수. 1마리면 두 번째 자리가 점잡음으로 보임 = 시험 조건 문제). `STATE`/`NOLEFT`/`A1`/`A2` 환경변수로 다른 저장 상태·롬(원본 v1.6: A1=0x0227cc98 A2=0x022bc81c)에도 쓸 수 있음.
- `evo.py` 의 `PARTNER=종번호` — 「파티 종」 진화 시험. `도구진화_변환시험.py` — 도구 사용 진화 줄을 「Lv20 레벨 진화」로 바꾼 시험 롬으로 대상 종 진화 확인(가방 없이 하는 대체 시험).
- `지도_이동시험.py <분담 i/n> <간격>` (+`지도_이동시험_촬영.py`) — 스크립트 Warp(명령 176)로 지도 이동 후 화면 촬영. 환경변수 `ROMF`(롬)·`STATE`·`NOLEFT`·`OUT` 으로 원본 롬과 같은 조건 비교 가능. 좌표는 지도 이벤트의 첫 워프 칸이라 일부 지도는 지도 밖 좌표가 되어 검은 화면(원본도 동일).
