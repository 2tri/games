# 디지몬 팬 게임 기획 (가제 미정, 비공식·비영리)

「디지몬스터」(포켓몬스터 금 한글판 개조)를 모티브로 한 게임보이 컬러 감성의 웹 RPG.
**들어가는 것은 디지몬뿐이다.** 디지몬스터에 남아 있던 포켓몬 요소(지도·마을 이름·관장·아이템·기술·타입)까지 디지몬으로 바꾼다.

### 화면에서 확인한 것 (스크린샷·영상 장면 약 90장)
| 부분 | 디지몬스터에서 본 것 |
|---|---|
| 타이틀 | 「디지몬 어드벤처」풍 주황 로고 + 금판의 구름 하늘. 2.0판은 파란 「디지몬」 로고 + 문장 무늬 |
| 시작 | 겐나이가 "디지몬스터의 세계에 잘왔단다!" → 아구몬을 보여 줌 → 고글 쓴 소년(파란 옷)의 이름 정하기. 이름 후보: 유민·소룡·태일·강산 |
| 전투 | 금판 배치 그대로. 메뉴 「싸우다 · 가방 · 디지몬 · 도망치다」. 상대 위 오른쪽, 내 디지몬 뒷모습 왼쪽 아래 |
| 이름 | 한국 방영판 이름 (쉬라몬, 파닥몬, 황제드라몬, 듀크몬, 그라우몬). **5글자 제한**이라 「알포스퓨처」처럼 잘림 → 아카라이브 글에서 "몰입도 확 깨진다"는 지적 |
| 도감 | 번호 + 분류(예: 성기사디지몬, 용인형디지몬) + 키·무게 + 설명문. 예: No.029 이그드라실, No.200 오메가몬X, No.235 알파몬왕룡검 |
| 타입 | 포켓몬 타입을 그대로 쓰고 「빛」을 추가 (엔젤몬 격투/빛). 이그드라실은 「???」 |
| 기술 | 포켓몬 기술(들이박기·할퀴기·연막)과 디지몬 필살기(메가플레임·로열세이버·쿼바디스·파이널엘리시온·크림존소드)가 섞여 있음 |
| 진화 | 레벨 진화 ("축하합니다! 엑스브이몬는(은) 황제드라몬(으)로"). 진화의 돌 대신 **진화 카드**(진화·불꽃·천둥·물 카드)를 상점에서 판매 |
| 알 | 알이 부화해서 디지몬을 얻음 (파닥몬) |
| 회복 | 포켓몬센터 자리에서 "당신의 디지몬을 쉬게 하겠습니까?" |
| 지도 | 성도·관동 지도와 마을 이름(진청·무궁·금빛·상록 등)을 그대로 씀. 2017판은 첫 마을이 「시작마을」 |
| 관장·사천왕 | 금판 관장 이름이 일부 남음(류옹이 메탈시드라몬 사용). 새 인물도 있음(관장 산들, 사천왕 굳건) |
| 후반 | 로얄나이츠를 잡은 뒤 숨겨진 이그드라실(Lv100). 제작자 엘클이 상대로 나옴. 은빛산 상대는 Lv100 풀파티 |
| 그림 규격 | 앞모습 40×40~56×56, 흰·검 포함 4색 (흰·검을 빼면 2색) — 아카라이브 댓글 |

### 확인하지 못한 것
- 네이버 카페 원문: `cafe.naver.com`이 허용 목록에 없음. 회원 전용일 가능성 있음 (**불확실함**)
- 나무위키: 사이트가 봇 차단(Cloudflare 확인 화면)을 걸어 열 수 없음
- 유튜브 영상 본편: 로그인 요구. 영상 장면 이미지(썸네일)만 확인
- 그래서 **전체 디지몬 목록, 스타팅 디지몬, 관장 8명 전원은 확인하지 못함**

## 2. 확정 사항 (2026-10-01 사용자 결정)
| 항목 | 결정 |
|---|---|
| 지도 | **디지털 월드 지명** (성도·관동 대신). 예: 파일섬, 행복의 마을 |
| 등장 디지몬 | **디지몬 어드벤처 + 파워 디지몬(어드벤처 02 한국 방영판)에 나온 디지몬만.** 테이머즈(길몬·레나몬·테리어몬·듀크몬 등)와 그 뒤 작품은 뺀다 |
| 타입 | **공식 속성**: 백신 · 데이터 · 바이러스 · 프리 (공식 도감의 「속성」 칸) |
| 주인공 | **애니 인물 중 고르기** (선택받은 아이들). 고른 아이의 파트너가 첫 디지몬 |
| 디지몬 얻기 | **② 디지타마(알) 부화 + ③ 이긴 야생 디지몬이 동료가 되기도 함.** 포획 아이템 없음 |

### 주인공 후보와 파트너
- 이름: 루리위키 「디지몬 어드벤처」·「파워 디지몬」 등장인물 표기 (한국 방영판)
- 디지몬 이름·등급: 디지몬 공식 한국어 도감

| 작품 | 아이 | 파트너 (등급) |
|---|---|---|
| 디지몬 어드벤처 | 신태일 | 아구몬 (성장기) |
| | 매튜 | 파피몬 |
| | 한소라 | 피요몬 |
| | 장한솔 | 텐타몬 |
| | 이미나 | 팔몬 |
| | 정석 | 쉬라몬 |
| | 리키 | 파닥몬 |
| | 신나리 | 가트몬 (성숙기) |
| 파워 디지몬 | 최산해 | 브이몬 (성장기) |
| | 홍예지 | 호크몬 (성장기) |
| | 이재하 | 아르마몬 (성장기) |
| | 서정우 | 추추몬 (성장기) |
- 리키·신나리는 두 작품에 모두 나오므로 한 번만 넣는다.
- 고르기 화면 1쪽은 어드벤처 8명, 2쪽은 파워 디지몬 4명.

### 속성 상성
- 백신 → 바이러스 → 데이터 → 백신 (화살표 방향으로 강함). 프리는 상성 없음
- 근거: 디지몬 스토리 시리즈 등 디지몬 게임의 규칙. 배율(몇 배)은 **확인 필요**, 정하기 전까지 강함 1.5배 / 약함 0.75배로 둔다

### 디지털 월드 지명·인물 (한국 방영판)
| 원작 | 한국 방영판 | 근거 |
|---|---|---|
| 파일섬 | 파일섬 | 검색 요약 (**확인 필요**) |
| 시작의 마을 | 행복의 마을 | 검색 요약: 나무위키 「시작의 마을」 (원문은 봇 차단으로 못 봄, **확인 필요**) |
| 겐나이 | 흰수염 도사 | 검색 요약: 나무위키 「흰수염 도사」 (**확인 필요**) |
| 행복의 마을 관리인 | 에렉몬 | 공식 도감 이름 |
- 그 밖의 지명(서버 대륙, 스파이럴 마운틴 등)은 근거를 찾은 뒤에 넣는다.

## 3. 디지몬스터에서 가져올 것 / 바꿀 것
### 그대로 가져옴
- 게임보이 컬러 금판 화면과 배치 (160×144, 글상자, HP 막대, 경험치 막대)
- 전투 메뉴: 싸우다 · 가방 · 디지몬 · 도망치다
- 오프닝: 흰수염 도사 → 디지몬 소개 → 주인공 고르기
- 레벨 진화 + 진화 카드, 알 부화
- 도감: 번호·등급·유형·속성·필살기
- 그림: 디지몬마다 대표색 2개 + 흰색·검정 (디지몬스터 그림 방식)

### 바꿈
| 디지몬스터 | 우리 게임 |
|---|---|
| 성도·관동 지도와 마을 이름 | 디지털 월드 지명 |
| 테이머즈 등 여러 작품의 디지몬 | 어드벤처 + 파워 디지몬 디지몬만 |
| 포켓몬 타입 + 빛 | 공식 속성 4종 |
| 포켓몬 기술 | 공식 도감의 필살기 |
| 고글 소년 1명 | 선택받은 아이 12명 중 고르기 |
| 몬스터볼 포획 | 디지타마 부화 + 이긴 야생 디지몬 합류 |
| 금판 관장·밈 인물 | 어드벤처·파워 디지몬 인물과 디지몬 |
| 후반 로얄나이츠 → 이그드라실 | 두 작품의 적으로 교체 (후보: 데블몬, 에테몬, 묘티스몬, 다크마스터즈, 아포카리몬, 디지몬 카이저 등. 공식 이름 확인 후 확정) |
| 이름 5글자 제한 | 제한 없음 |

## 4. 이름·자료 기준
- 디지몬 이름·등급·유형·속성·필살기·진화 관계: 디지몬 공식 한국어 도감 (digimon.net/reference_ko)
  - 예: 아구몬 = 성장기 · 파충류형 · 백신 · 베이비 플레임 / 코로몬 → 아구몬 → 그레이몬
  - 예: 그레이몬 = 성숙기 · 공룡형 · 백신 · 메가파이어 / 쿠가몬 = 성숙기 · 곤충형 · 바이러스 · 시저 암즈
- 도감 설명문은 공식 문장을 베끼지 않고 새로 쓴다.
- 그림은 공식 그림·디지몬스터 롬 그림을 가져오지 않고 코드로 새로 찍는다.

## 6. 만드는 순서
1. **시안 확정** (지금 단계)
2. **엔진**: 화면·조작, 글상자·메뉴, 필드 걷기·충돌·대화, 야생 전투, 레벨·경험치·진화, 알 부화, 동료 합류, 저장
3. **1장 파일섬**: 행복의 마을 → 주변 지역, 디지몬 15~20종, 첫 우두머리
4. 지역을 하나씩 추가
- 각 단계마다 화면을 먼저 보여 주고 확인받은 뒤 만든다.
