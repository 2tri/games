# 디지몬 팬 게임 기획 (가제 미정, 비공식·비영리)

「디지몬스터」(포켓몬스터 금 한글판 개조)를 모티브로 한 게임보이 컬러 감성의 웹 RPG.
**들어가는 것은 디지몬뿐이다.** 디지몬스터에 남아 있던 포켓몬 요소(지도·마을 이름·관장·아이템·기술·타입)까지 디지몬으로 바꾼다.

| 등장 디지몬 | **디지몬 어드벤처 + 파워 디지몬(어드벤처 02 한국 방영판)에 나온 디지몬만.** 테이머즈(길몬·레나몬·테리어몬·듀크몬 등)와 그 뒤 작품은 뺀다 |

## 3. 디지몬스터에서 가져올 것 / 바꿀 것
### 그대로 가져옴
- 게임보이 컬러 금판 화면과 배치 (160×144, 글상자, HP 막대, 경험치 막대)
- 전투 메뉴: 싸우다 · 가방 · 디지몬 · 도망치다
- 오프닝: 흰수염 도사 → 디지몬 소개 → 주인공 고르기
- 레벨 진화 + 진화 카드, 알 부화
- 도감: 번호·등급·유형·속성·필살기
- 그림: 디지몬마다 대표색 2개 + 흰색·검정 (디지몬스터 그림 방식)

### 바꿈
| 디지몬스터 | 우리 게임 |
|---|---|
| 성도·관동 지도와 마을 이름 | 디지털 월드 지명 |
| 테이머즈 등 여러 작품의 디지몬 | 어드벤처 + 파워 디지몬 디지몬만 |
| 포켓몬 타입 + 빛 | 공식 속성 4종 |

| 이름 5글자 제한 | 제한 없음 |

## 4. 이름·자료 기준
- 디지몬 이름·등급·유형·속성·필살기·진화 관계: 디지몬 공식 한국어 도감 (digimon.net/reference_ko)
  - 공식 한국어 이름은 한국 방영판 이름 기준이다. 예: 퍼펫몬(몬자에몬), 묘티스몬, 파워드라몬, 프리지몬, 개굴몬, 시드몬, 우가몬, 쿠가몬, 파피몬
  - 도감에서 이름을 찾지 못한 디지몬은 **(확인 필요)** 로 두고 게임에 넣지 않는다
- 도감 설명문은 공식 문장을 베끼지 않고 새로 쓴다.
- 그림: 디지몬스터 그림을 엘클 님 허락(사용자가 개인 메일로 받음) 아래 쓴다. 최신판은 사용자가 찾는 중.
  - 롬 파일과 롬에서 뽑은 그림은 **공개 저장소에 올리지 않는다** (허락 범위 확인 전)
  - 롬에 섞여 있는 포켓몬 그림, 금판 UI 그림은 쓰지 않는다. UI는 `ui.js`로 새로 그린 것을 쓴다

## 5. 스토리·구성 (1차안 — 바꿀 수 있음)

### 큰 구조 (금판 → 우리 게임)
| 금판 | 우리 게임 |
|---|---|
| 성도 지방 · 배지 8개 | **1부 「디지몬 어드벤처」** — 디지털 월드, **문장 8개** |
| 사천왕 → 챔피언 | **다크마스터즈 넷** (메탈시드라몬 · 피노키몬 · 파워드라몬 · 피에몬) → **아포카리몬** |
| 엔딩 뒤 관동 지방 · 배지 8개 | **2부 「파워 디지몬」** — 3년 뒤, 디지몬 카이저와 어둠의 탑, **디지멘탈 8개** |
| 은빛산의 레드 | 숨겨진 상대 (후보: 블랙워그레이몬) |

### 주인공 (제안: 앞의 결정을 조금 고침)
- 1부 시작 때 **어드벤처 아이 8명 중 한 명**을 고른다. 파워 디지몬 아이들은 1부 시점에 아직 선택받기 전이라서다.
- 2부는 같은 주인공이 3년 뒤 중학생이 되어 이어 간다. 최산해 · 홍예지 · 이재하는 동료, 서정우는 디지몬 카이저로 나왔다가 동료가 된다.
- 고르지 않은 아이 7명은 이야기 속 동료로 나온다. 문장을 하나 얻을 때마다 그 문장의 아이가 일행에 합류한다.

### 1부 진행 — 문장 8개 = 배지 8개
| 순서 | 무대 | 우두머리 | 문장 (주인) | 비고 |
|---|---|---|---|---|
| 프롤로그 | 현실 세계 · 여름 캠프 | — | — | 오로라 → 디지바이스 → 디지털 월드로 떨어짐 |
| 1 | 파일섬 해변 | 쉘몬 | 성실 (정석) | 행복의 마을에서 출발, 첫 진화 |
| 2 | 파일섬 숲 | 쿠가몬 | 지식 (장한솔) | |
| 3 | 파일섬 산 | 레오몬 (조종당함) | 우정 (매튜) | 레오몬은 이긴 뒤 동료 |
| 4 | 파일섬 꼭대기 | 데블몬 | 희망 (리키) | 1장 끝 |
| 5 | 서버 대륙 · 개굴몬 성 | 왕개굴몬 | 순수 (이미나) | |
| 6 | 서버 대륙 · 장난감 마을 | 퍼펫몬 | 사랑 (한소라) | |
| 7 | 서버 대륙 · 사막 | 에테몬 | 용기 (신태일) | |
| 8 | 현실 세계 | 묘티스몬 | 빛 (신나리) | 가트몬·위자몬 합류 |
| 사천왕 | 다크마스터즈 영역 | 메탈시드라몬 → 피노키몬 → 파워드라몬 → 피에몬 | — | |
| 챔피언 | 마지막 싸움 | 아포카리몬 | — | 1부 엔딩 |
- 서버 대륙 · 장난감 마을 · 개굴몬 성 같은 지명은 한국 방영판 표기 **확인 필요**. 확인 전까지는 임시 이름이다.
- 우두머리와 문장 짝짓기는 게임용으로 정한 것이고, 애니 회차 순서와 같지 않다.

### 2부 진행 — 디지멘탈 8개 = 관동 배지 8개
- 3년 뒤 디지털 월드에 어둠의 탑이 서고, 기존 진화가 막힌다 → **아머 진화**(공식 등급 「아머체」)를 디지멘탈로 한다.
- 디지멘탈과 아머체 (공식 이름 확인된 것): 용기 → 화염드라몬, 우정 → 번개드라몬, 사랑 → 호루스몬, 지식 → 디그몬, 희망 → 페가수스몬, 빛 → 네페르티몬. 순수·성실의 아머체는 **확인 필요**
- 우두머리 후보: 디지몬 카이저(서정우)와 키메라몬, 미이라몬, 블랙워그레이몬, 베리얼묘티스몬 (최종)

### 디지몬 얻기
- **디지타마(알)**: 마을·이벤트에서 받고 들고 걸으면 부화. 유아기Ⅰ(깜몬·푸니몬) → 유년기Ⅱ(코로몬·뿔몬·모티몬·시드몬·토코몬·야옹몬) → 성장기로 자람
- **이긴 야생 디지몬**: 전투에서 이기면 일정 확률로 "동료가 되고 싶은 듯 바라본다" → 예/아니오

### 진화
| 단계 | 방법 |
|---|---|
| 유아기 → 유년기 → 성장기 | 레벨 |
| 성장기 → 성숙기 | 레벨 |
| 성숙기 → 완전체 | 파트너: 그 아이의 **문장**을 얻은 뒤 레벨 / 그 밖의 디지몬: 레벨 + 진화 카드 (디지몬스터 방식) |
| 완전체 → 궁극체 | 1부 후반 이벤트 (워그레이몬 · 메탈가루몬 등) |
| 성장기 → 아머체 | 2부, 디지멘탈 |

## 6. 지금까지 만든 것
- `ui.js` 금판식 화면 부품 (디지몬스터 전투 화면을 재서 같은 자리·크기로), `font.js` 갈무리11 Condensed 한글 비트맵
- `pix.js` 도트 도구, `mons.js` · `field.js` 직접 그린 시험 그림 (디지몬스터 그림이 들어오면 바꿈)
- 롬에서 그림 풀기 확인: 2014년 초기판 롬에서 그림 251칸을 풀었음. 디지몬 약 100종 + 포켓몬이 섞여 있음 (작업 폴더에서만 확인, 저장소에 안 올림)

## 7. 만드는 순서
1. **스토리·구성 확정** (지금 단계)
2. **엔진**: 화면·조작, 글상자·메뉴, 필드 걷기·충돌·대화, 야생 전투, 레벨·경험치·진화, 알 부화, 동료 합류, 저장
3. **프롤로그 + 1장 파일섬**: 행복의 마을 → 해변 → 숲 → 산 → 꼭대기 (문장 4개)
4. 서버 대륙 → 현실 세계 → 다크마스터즈 → 2부
- 그림은 최신판을 받으면 넣는다. 각 단계마다 화면을 먼저 보여 주고 확인받은 뒤 만든다.
