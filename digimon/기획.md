# 디지몬 팬 게임 기획 (가제 미정, 비공식·비영리)

「디지몬스터」(포켓몬스터 금 한글판 개조)를 모티브로 한 게임보이 컬러 감성의 웹 RPG.
**들어가는 것은 디지몬뿐이다.** 디지몬스터에 남아 있던 포켓몬 요소(지도·마을 이름·관장·아이템·기술·타입)까지 디지몬으로 바꾼다.

## 2. 확정 사항 (2026-10-01 사용자 결정)
| 항목 | 결정 |
|---|---|
| 지도 | **디지털 월드 지명** (성도·관동 대신). 예: 파일섬, 행복의 마을 |
| 등장 디지몬 | **디지몬 어드벤처 + 파워 디지몬(어드벤처 02 한국 방영판)에 나온 디지몬만.** 테이머즈(길몬·레나몬·테리어몬·듀크몬 등)와 그 뒤 작품은 뺀다 |
| 타입 | **공식 속성**: 백신 · 데이터 · 바이러스 · 프리 (공식 도감의 「속성」 칸) |

### 속성 상성
- 백신 → 바이러스 → 데이터 → 백신 (화살표 방향으로 강함). 프리는 상성 없음
- 근거: 디지몬 스토리 시리즈 등 디지몬 게임의 규칙. 원작 게임의 배율은 **확인 필요**
- GBC판 배율 (2026-10-01 밸런스): 강함 1.25배 / 약함 0.8배. 디지몬은 속성이 하나뿐이라 포켓몬(2배/0.5배)처럼 크게 하면 상성이 나쁜 파트너는 첫 우두머리를 못 넘는다

### 피해 계산 (GBC판, 2026-10-01 밸런스)
- 금판 공식 그대로: ((Lv×2/5+2) × 위력 × 공격/방어)/50 + 2, 급소 1/16 (2배), 난수 85~100%
- **필살기 1.5배** (포켓몬 자속 보정 자리)
- **공격·방어·스피드 = 30 + 기본값/2** 로 계산 (체력은 그대로): 성숙기와 성장기의 차이를 반으로 줄여 초반 성숙기 우두머리가 한 방에 이기지 않게
- **위력 상한 = 20 + 3×Lv**: 레벨이 낮은 디지몬은 큰 필살기도 힘을 다 못 냄 (Lv10 → 50, Lv25 → 95)
- 확인: 상성 불리한 아구몬이 회복 아이템 없이 필살기만으로 쉘몬 Lv9와 싸우면 Lv11은 이길 때도 질 때도 있고, Lv12는 이김 (PyBoy 시험). 회복 디스크를 쓰면 Lv10~11도 충분

## 3. 디지몬스터에서 가져올 것 / 바꿀 것
### 그대로 가져옴
- 게임보이 컬러 금판 화면과 배치 (160×144, 글상자, HP 막대, 경험치 막대)
- 전투 메뉴: 싸우다 · 가방 · 디지몬 · 도망치다
- 오프닝: 흰수염 도사 → 디지몬 소개 → 주인공 고르기
- 레벨 진화 + 진화 카드, 알 부화
- 도감: 번호·등급·유형·속성·필살기
- 그림: 디지몬마다 대표색 2개 + 흰색·검정 (디지몬스터 그림 방식)

## 4. 이름·자료 기준
- 디지몬 이름·등급·유형·속성·필살기·진화 관계: 디지몬 공식 한국어 도감 (digimon.net/reference_ko)
  - 공식 한국어 이름은 한국 방영판 이름 기준이다. 예: 퍼펫몬(몬자에몬), 묘티스몬, 파워드라몬, 프리지몬, 개굴몬, 시드몬, 우가몬, 쿠가몬, 파피몬
  - 도감에서 이름을 찾지 못한 디지몬은 **(확인 필요)** 로 두고 게임에 넣지 않는다
- 도감 설명문은 공식 문장을 베끼지 않고 새로 쓴다.
- 그림: 디지몬스터 그림을 엘클 님 허락(사용자가 개인 메일로 받음) 아래 쓴다. 최신판은 사용자가 찾는 중.
  - 롬 파일과 롬에서 뽑은 그림은 **공개 저장소에 올리지 않는다** (허락 범위 확인 전)
  - 롬에 섞여 있는 포켓몬 그림, 금판 UI 그림은 쓰지 않는다. UI는 `ui.js`로 새로 그린 것을 쓴다

### 2부 진행 — 디지멘탈 8개 = 관동 배지 8개

### 디지몬 얻기 (2026-10-01 갱신: 「디지몬 RPG」 포획 오마주)
- **포획**: 전투 중 가방에서 —
  - **디지바이스** (오로라에서 받음, 안 닳음): 한 번 싸움에 3번, **유년기만**, 확률 낮음
  - **유년기 그물** (상점 200비트): 유년기를 잘 잡음
  - **성장기 그물** (상점 600비트): **성장기까지** 잡을 수 있음
  - 성숙기 이상은 잡을 수 없음 ("데이터가 너무 강해서 튕겨 나갔다"), 우두머리는 못 잡음
  - 상대 체력이 적을수록 잘 잡힘. 근거: 「디지몬 RPG」는 포획 명령 3번·유년기만, 포획그물(유년기·성장기용)로 잡음 (Wikipedia Digimon Battle Online, 나무위키 검색 결과)
- **디지타마(알)**: 마을·이벤트에서 받고 들고 걸으면 부화
- 이겨도 자동으로 동료가 되지 않는다 (예전 안 폐기). 대신 **비트**(돈)를 얻는다

### 진화 (2026-10-01 갱신: 정해진 대로만 진화하지 않게 — 문장 진화·암흑 진화·갈래 진화)
| 단계 | 방법 |
|---|---|
| 유아기 → 유년기 → 성장기 | 레벨 |
| 성장기 → 성숙기 (Lv14) | **유대**로 갈래: 60 이상 = 본래 진화 (그레이몬) · 20~59 = 다른 진화 (티라노몬) · 20 미만 = 실패 진화 (워매몬) |
| 성숙기 → 완전체 (Lv30) | **문장 아무거나 1개 이상** 필요 (문장은 이야기 순서로 얻지만 진화 순서는 묶이지 않음). 자기 문장이 있으면 **문장 진화** ("문장이 눈부시게 빛난다!"). 자기 문장이 없고 암흑 모습이 있으면 "그래도 진화시킬까?" → **암흑 진화**. 유대가 20 미만이면 묻지 않고 억지로 암흑 진화 |
| 물건 진화 | **검은 톱니** (데블몬을 이기면 얻음): 그레이몬 → 스컬그레이몬, 가트몬 → 레이디데블몬. **이블 스파이럴** (2부 예정): 그레이몬 → 메탈그레이몬(바이러스종) |
| 되돌리기 | 회복 센터에서 에렉몬이 암흑 진화체를 원래 성숙기로 되돌려 줌 (원작: 스컬그레이몬이 폭주 뒤 퇴화) |
| 멈추기 | 진화 장면에서 B → 멈춤, 다음 레벨업에 다시 (포켓몬 오마주). 이야기·암흑·물건 진화는 못 멈춤 |
| 완전체 → 궁극체 | 1부 후반 이벤트 (워프 진화: 워그레이몬 · 메탈가루몬 등) |
| 성장기 → 아머체 | 2부, 디지멘탈 (용기·우정·사랑·지식·성실·순수·희망·빛 — 문장과 같은 무늬) |

**유대** (디지몬마다 0~250, 능력 보기에 ♥ 5칸)
- 처음: 이야기 파트너·디지타마 50, 포획 20
- 싸움에서 이기면 +2 (우두머리 +4), 쓰러지면 −10 (디지몬 월드의 "돌봄 실수" 오마주), **고기**(상점 50비트) +10·체력 20 회복
- 암흑 진화체는 싸움 중 30% 폭주 (명령 무시, 아무 기술)

**갈래 표** (본래 / 다른 / 실패 → 완전체)
