# 디지몬 팬 게임 기획 (가제 미정, 비공식·비영리)

「디지몬스터」(포켓몬스터 금 한글판 개조)를 모티브로 한 게임보이 컬러 감성의 웹 RPG.
**들어가는 것은 디지몬뿐이다.** 디지몬스터에 남아 있던 포켓몬 요소(지도·마을 이름·관장·아이템·기술·타입)까지 디지몬으로 바꾼다.

---

## 0. 방향 바꿈 (2026-10-01 밤, 사용자 결정) — 아래 1~7장보다 우선
- **새 게임을 만들지 않는다.** 엘클 님께 허락받은 「디지몬스터」 롬을 한 번 더 고쳐 「내 버전」을 만든다.
- 지도·기술·이펙트·전투·메뉴는 금/디지몬스터 것을 그대로 쓴다. 그림은 롬에 없는 디지몬과 다시 그릴 디지몬만 새로 받는다 (주문서 아티팩트, `romhack/order/`).
- 내 버전에서 바꾸는 것: 진화(유대 갈래 · 문장 = 배지 · 암흑 진화) / 포획(유년기·성장기만) / 빠진 어드벤처·02 디지몬 / 디지몬스터 버그 / 대사(정해야 함).
- 도구: `romhack/` (README 참고). 롬·고친 롬·패치·롬에서 뽑은 그림은 `romhack/work/`에만 두고 저장소에 안 올린다.
- 직접 만든 GBC 엔진 `gbc/`는 멈춤(시험판으로 보관). 5장 이야기 설계와 받은 그림은 롬 개조에 그대로 쓴다.

### 1.4판 디지몬만으로 채울 수 있나 (2026-10-01 점검)
- 위키몬 에피소드 기록(어드벤처 54화·02 50화·극장판 4편)에 이름이 나온 디지몬 225개 → 알·중복 표기·테이머즈 단역(테리어몬·로프몬 등)을 빼면 **약 205종**. 그중 41종은 한 번만 나옴.
- 롬에 이미 있는 어드벤처 디지몬 68종 + 새로 넣은 3칸(코로몬·메탈그레이몬·워가루몬) → **그림이 더 필요한 것 약 134종** (필수 15 + 나중 119).
- 251칸보다 약 45종 모자람 → 남는 칸은 야생·트레이너·이벤트에 안 나오게 비워 둔다 (도감에는 빈 줄). 더 채우려면 어드벤처 tri.·키즈나까지 넓히는 방법이 있음 (정해야 함).
- 기술적으로 걸리는 칸: 안농(201, 알프의 유적 전용 코드), 전설 이벤트 칸(243~245 떠도는 셋, 249·250), 길을 막는 고정 만남(143·185), 분노의 호수(130), 공박사 알(175) — 칸 번호에 이벤트가 붙어 있으므로 우두머리 디지몬을 넣는 자리로 쓴다.
- 그림 말고도 필요한 것: 파티 메뉴 아이콘(지금 전부 포켓몬 아이콘), 필드에 서 있는 포켓몬 그림(길막·인형), 대사.
- 디지몬스터 버그를 더 찾음: 기술 목록이 (기술, 레벨) 순서로 뒤집힌 6종(워그레이몬·황제드라몬 등), 홀리엔젤몬 진화 목록 겹침 → 고침.

### 계획 v0.4 (2026-10-02, 자문 계획서 v0.3 검토 반영) — 아티팩트 「디지몬스터 내 버전 계획」
- 작업 순서: A 잔재 치환(야생·트레이너·이벤트·경품·낚시 표의 포켓몬과 뺄 종 → 그림 있는 71종) → B 진화·포획 표 → C 상대 파티(관장 에이스 = 문장 주인 파트너, 사천왕 = 어둠의 4천왕, 챔피언 = 아포카리몬, 레드 = 태일, 로켓단 = 암흑단) → D 대사·도구 1차(같은 길이 치환) → E 새 종 설치 → F 색만 바꾼 종 → G 아이콘 → H 관동 → I 울음.
- 자문안에서 고친 것 (근거: 롬·pokegold-kr 디스어셈블리·위키몬 애니 등장 기록):
  - 주작몬·현무몬·백호몬은 테이머즈라 뺌 (청룡몬만 02 34화). 블랙아구몬·블랙가부몬·블랙가트몬, 오파니몬, 하이안드몬은 등장 기록 없음.
  - 바케몬 = 고스몬 (같은 디지몬). 236 배루키는 탁마산 이벤트 칸. 퍼펫몬은 어둠의 4천왕이 아님.
  - 한글판 도감 글 뱅크는 2구간(1~128 → 68, 129~251 → 69). 분기 코드는 뱅크 11 (빈 곳 13.7KB).
  - 금 친밀도는 시작 70, 레벨업 +5(100 미만)·+3(200 미만) → 지금 유대 높음 ≥100 은 Lv16에 거의 항상 충족.
  - 빌의 이브이 = 133 브이몬 (스타팅과 겹침). 경품·함정·선물 칸도 A단계에서 같이 바꿈.
- 그림 주문문 v3: 화풍만 바꾸는 「스타일 변환」, 앞·뒤 따로, 회색 4톤, 「포켓몬」 단어 없음. 종별 값은 `romhack/order/specs.py`, LCD 도트 링크 `order/lcd.json`, 받은 그림은 `ingest.py 그림 id --side f|b [--flat]`.

### A단계 결과 (2026-10-02)
- 롬에서 종을 가리키는 곳 3,492곳을 모두 찾음 (`encounters.py`, 개수는 디스어셈블리와 일치): 풀숲 1,911 · 트레이너 1,154 · 낚시 152 · 대량발생 87 · 물 72 · 박치기 나무 36 · 고정 만남 18 · 선물 16 · 경품 9 · 교환 12 · 떠돌이 3 · 벌레잡기 대회 11 · 알 1.
- `mapping.csv`(152줄)대로 2,529곳을 바꿈 → **포켓몬·뺄 종을 가리키는 곳 0** (안농만 그대로, D단계에서 「디지문자」).
- 야생은 Lv20 미만 유년기·성장기, Lv20 이상 성숙기까지. 완전체·궁극체는 야생에 없음. 스타팅 줄과 플롯트몬은 야생에 안 나옴.
- 경품: 금빛 위자몬·추추몬·쉬라몬, 무지개 가트몬·텐타몬·안드로몬 (메뉴 글도 바꿈). 빌 = 플롯트몬, 진청시티 단단지 = 디지타마몬, 탁마산 = 에렉몬. 빌 할아버지 확인 종도 같이 바꿈(대사는 D단계).
- 쿠가몬 계획 칸을 13 → 185(꼬지모 길막)로 옮김. 새 칸 14종을 임시 그림으로 넣어 보면 각자 자기 자리에 그대로 나옴(확인함).
- 남은 것: 야생 종이 32종뿐이라 단조로움(새 종이 들어오면 늘어남), 유년기가 높은 레벨에도 나옴(뿔몬 Lv27 등), 트레이너 파티는 C단계에서 다시 짬.

## 4. 이름·자료 기준
- 디지몬 이름·등급·유형·속성·필살기·진화 관계: 디지몬 공식 한국어 도감 (digimon.net/reference_ko)
  - 공식 한국어 이름은 한국 방영판 이름 기준이다. 예: 퍼펫몬(몬자에몬), 묘티스몬, 파워드라몬, 프리지몬, 개굴몬, 시드몬, 우가몬, 쿠가몬, 파피몬
  - 도감에서 이름을 찾지 못한 디지몬은 **(확인 필요)** 로 두고 게임에 넣지 않는다
- 도감 설명문은 공식 문장을 베끼지 않고 새로 쓴다.
- 그림: 디지몬스터 그림을 엘클 님 허락(사용자가 개인 메일로 받음) 아래 쓴다. 최신판은 사용자가 찾는 중.
  - 롬 파일과 롬에서 뽑은 그림은 **공개 저장소에 올리지 않는다** (허락 범위 확인 전)
  - 롬에 섞여 있는 포켓몬 그림, 금판 UI 그림은 쓰지 않는다. UI는 `ui.js`로 새로 그린 것을 쓴다

### 디지몬 얻기 (2026-10-01 갱신: 「디지몬 RPG」 포획 오마주)
- **포획**: 전투 중 가방에서 —
  - **디지바이스** (오로라에서 받음, 안 닳음): 한 번 싸움에 3번, **유년기만**, 확률 낮음
  - **유년기 그물** (상점 200비트): 유년기를 잘 잡음
  - **성장기 그물** (상점 600비트): **성장기까지** 잡을 수 있음
  - 성숙기 이상은 잡을 수 없음 ("데이터가 너무 강해서 튕겨 나갔다"), 우두머리는 못 잡음
  - 상대 체력이 적을수록 잘 잡힘. 근거: 「디지몬 RPG」는 포획 명령 3번·유년기만, 포획그물(유년기·성장기용)로 잡음 (Wikipedia Digimon Battle Online, 나무위키 검색 결과)
- **디지타마(알)**: 마을·이벤트에서 받고 들고 걸으면 부화
- 이겨도 자동으로 동료가 되지 않는다 (예전 안 폐기). 대신 **비트**(돈)를 얻는다

### 진화 (2026-10-01 갱신: 정해진 대로만 진화하지 않게 — 문장 진화·암흑 진화·갈래 진화)
