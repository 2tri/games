- 도감 설명 글은 원작 글이라 이 파일엔 안 넣음(비공개 페이지에만)

## 다른 디지몬 게임에서 가져올 만한 것

1. 기술 이름: 공식 한국어 도감에 종마다 필살기 1~3개 (게임 속 98종 128개, 워가루몬·아포카리몬은 도감에 없음). 한국 방영판 이름과 다른 것 있음(가브몬 방영판 「파란 불꽃」 ↔ 도감 「쁘띠 파이어」, 가루다몬 방영판 「불새출격」) — 일부만 확인, 어느 이름을 쓸지 설계자 결정
2. 디지몬 스토리 사이버 슬루스: 종마다 고유 필살기, 진화하면 같은 계열의 더 센 필살기(아구몬 Pepper Breath 불 70 → 그레이몬 Mega Flame 불 95, Grindosaur). 속성 삼각 백신 → 바이러스 → 데이터 → 백신(2배/0.5배), 원소 상성 물 → 불 → 풀 → 물, 땅 → 전기 → 바람 → 땅, 빛 ↔ 어둠(1.5배) (KeenGamer·Player.One)
3. 옮기는 법(제안): 필살기 줄 잇기(성장기 → 성숙기 → 완전체 같은 성격·높은 위력), 원소 상성은 금 타입 상성으로 거의 됨(물·불꽃·풀 / 땅 → 전기 → 비행, 빛·어둠은 에스퍼 ↔ 악), 백신·데이터·바이러스는 엔진 코드 필요(6-4의 7단계)
