# GBC 판 노래 → MIDI (2부 NDS 편곡용)

만든 법: `digimon/gbc/tools/json2mid.py` — GBC 롬에 넣은 편곡(`digimon/gbc/music/<곡>.json`)을 그대로 MIDI 로 되돌림.
원본 MIDI(편곡 전)는 저장소에 없어 「_원본구간」 파일은 없음.

- 트랙: 0 템포·마커 / 1 멜로디(펄스1) / 2 화음(펄스2) / 3 베이스(웨이브) / 4 북(노이즈 → GM 드럼, 채널 10)
- 마커: `loopStart` = 반복 시작, `loopEnd` = 곡 끝(반복 끝). 전주가 없는 곡은 `loopStart` 가 0초(처음부터 통째로 반복)
- 템포: 롬 엔진에 들어간 정수 템포에서 계산한 실제 빠르기(1배). 롬은 델타 빨리감기용으로 이 반의 빠르기로 들어 있음(MUSIC_FF=2)
- 옥타브: 채널 단위로 옮긴 것(안녕 디지몬 멜로디 −12, digimon 록·The Biggest Dreamer 베이스 −12)은 되돌림. Brave Heart 화음의 반짝이 반복음(한 소스만 −12)과 GBC 음역(펄스 C2~C7, 웨이브 E1~C5)에 맞춘 자동 옥타브 접기는 음마다 기록이 없어 GBC 높이 그대로
- 화음·베이스는 원곡에서 한 번에 한 음만 고른 것 (GBC 채널 한계)
