# 그림 원화 프롬프트 (이미지 AI용) — 디지몬 팬 게임

이미지 AI(제미나이 등)로 그림을 뽑아 대화에 올리면, 칸 맞춤·4색 정리를 해서 GBC 롬과 웹판에 넣는다.
채팅에는 한 블록씩 떼서 준다 (폰에서 .md가 잘 안 열림). 이 파일은 전체 목록 보관용.

## 쓰는 법
- 블록 하나를 통째로 복사해 붙여넣기. 한 번에 한 장.
- **대화방 3개로 나눠서** 만들면 그림체가 맞춰진다: ① 배경·건물 ② 사람 걷기 그림 ③ 디지몬 전투 그림. 같은 방 안에서는 앞에 "같은 스타일로"를 붙인다(블록에 이미 들어 있음).
- 이름 때문에 거절하면 이름 부분만 지우고 다시.
- 크기는 AI가 정확히 안 지켜도 된다. 받은 뒤 이쪽에서 맞춘다.

## 받은 뒤 이쪽에서 하는 일
- 디지몬: `tools/snapc.py` → `art/<id>-f.png`·`-b.png` → 롬 다시 만들기 (`gbc/tools/build.py`)
- 배경: 칸 주기 찾기 → 16×16 칸으로 자르기 → 같은 칸 합치기 → 칸마다 GBC 팔레트 맞추기 → 지도 다시 짜기
- 사람: 칸 주기 찾기 → 동작별로 자르기 → 3색 + 투명으로
