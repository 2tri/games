# 그림 원화 프롬프트 (이미지 AI용) — 디지몬 팬 게임

반지 원정과 같은 방식: 이미지 AI(제미나이 등)로 그림을 뽑아 이 대화에 올리면, 칸 맞춤·4색 정리를 해서 게임에 넣는다 (`art.js`에 등록).

## 쓰는 법
- 블록 하나를 통째로 복사해 붙여넣는다. **같은 대화방에서 이어서** 만들면 그림체가 맞춰진다. 첫 장이 마음에 들면 다음부터 앞에 "같은 스타일로"를 붙인다.
- 한 번에 한 마리. 배경은 흰색 그대로 둔다.
- 디지몬 이름을 넣으면 거부하는 AI가 있을 수 있다 (**불확실함**). 거부되면 이름 부분만 지우고 생김새 설명으로 다시 요청.
- 크기(56x56 등)는 AI가 정확히 안 지켜도 된다. 받은 뒤 이쪽에서 맞춘다.
- 색: 금판처럼 **한 마리당 흰색·검은 테두리 + 몸 색 2가지**. 이쪽에서 4색으로 다시 묶으니 색이 조금 많아도 괜찮다.

## 공통 꼬리말 (아래 블록에 이미 들어 있음)
- 앞모습(적·도감): `Pokemon Gold and Silver Game Boy Color battle sprite style, pixel art, 56x56 pixels, only 4 colors: white, black, and two shades of the main color, 1 pixel black outline, 3/4 view facing left, dynamic pose, plain white background, single character, no text`
- 뒷모습(내 디지몬): `Pokemon Gold and Silver Game Boy Color player-side battle sprite seen from behind, over-the-shoulder back view looking toward the upper right, pixel art, 48x48 pixels, only 4 colors: white, black, and two shades of the main color, 1 pixel black outline, plain white background, no text`

## 2차 — 시험 삼아 (필드)
필드 걷기 그림(16x16)과 바닥 타일은 AI가 칸을 잘 안 지켜서 **될지 불확실함**. 1차가 잘 되면 한 장만 시험.
```
top-down overworld walking sprite sheet in the style of Pokemon Gold and Silver Game Boy Color, a boy with spiky brown hair and goggles, blue shirt, 4 directions (down, up, left, right) times 2 walking frames, each frame 16x16 pixels on a grid, only 4 colors, 1 pixel black outline, plain white background, no text
```
```
top-down RPG tileset in the style of Pokemon Gold and Silver Game Boy Color, 16x16 pixel tiles on a grid: grass, tall grass, dirt path, tree, flowers, sand beach, sea water, shoreline, wooden sign, only a few colors per tile, plain grid, no text
```

## 받은 뒤 이쪽에서 하는 일
1. 배경 지우기 → 도트 한 칸 크기 찾기 → 칸마다 색 하나로 → **흰색·검정 + 2색**으로 묶기
2. 앞 56칸 / 뒤 48칸 안에 바닥 맞춰 앉히기 → 잡티 지우기
3. `art.js`에 등록 → 실제 게임 화면 캡처로 보여 드림
