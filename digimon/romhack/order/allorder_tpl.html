디지몬스터 그림 주문서 (전체 종)

롬에 들어가는 디지몬 전부를 유년기부터 단계 순서로 놓았습니다. 종마다 지금 게임에서 보이는 앞·뒷모습과, 그림이 필요하면 어디서 구할지(게임 도트 후보 / 검색·재미나이)를 표시했어요.

완료 우리 그림이 롬에 들어감
그림 있음 · 롬에 넣을 차례 이 그림(「롬에 넣을 앞/뒤」)이 롬에 들어갑니다. 할 일 없음. 단, 새 칸은 앞·뒤가 다 있어야 생겨요
게임 도트 후보 다른 디지몬 게임(원더스완·GBA·NDS)의 도트를 4색으로 바꾼 후보가 있음 → 「후보 쓰기」 체크하면 그걸로 넣음
재미나이로 받아 주세요 쓸 만한 원본이 없음 → 카드의 주문문을 복사해 재미나이로 받아서 보내 주세요
1.4 그림 사용 중 디지몬스터 원래 그림 그대로. 바꾸고 싶으면 「다시 그리기」 체크

뒷모습 받는 법: 카드의 파란 테두리 「첨부용 앞모습」을 저장 → 재미나이에 첨부 1장으로 붙이고(공식 그림은 2장, 있으면) 「뒷모습 주문문 복사」를 붙여 넣기 → 받은 그림을 "○○ 뒤"로 보내 주세요. 앞모습 색과 크기에 맞춰 넣습니다.
뒷모습은 자동으로 못 만들어요. 다른 게임 도트는 전부 앞모습뿐이고, 앞모습을 좌우로 뒤집어도 등이 아니라 얼굴이 보여서 뒷모습이 안 돼요. 그래서 뒷모습은 재미나이로 받아야 해요 — 첨부 = 공식 그림 + 「롬에 넣을 앞」 그림, 「뒷모습 주문문 복사」. 주문 방법은 예전과 같습니다: 첨부 1장 LCD 도트(파란 테두리) · 2장 공식 그림 → 앞모습 주문문 / 뒷모습은 공식 그림 + 받은 앞모습 → 뒷모습 주문문.
