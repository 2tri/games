# 디지몬 GBC 롬 (Delta용)

`digimon.gbc` — 아이폰 **Delta** 에뮬레이터에서 여는 게임보이 컬러 롬. 저장은 배터리 저장(MBC5 + RAM)이라 Delta에서도 남는다.
웹판(`../index.html`)은 이야기·전투·밸런스를 빨리 확인하는 시험판이고, 최종 목표는 이 롬이다 (저장소 루트 `GBC_롬_가이드.md`).

## 폰에 넣기
1. GitHub에서 `digimon/gbc/digimon.gbc` → 「Download raw file」 → 파일 앱에 저장
2. Delta → `+` → 파일에서 `digimon.gbc` 선택

## 지금 들어 있는 것
- **이야기 길**: 제목 → 흰수염 도사 → 주인공 4명 중 고르기 → 내 방·1층 → 우리 동네(편의점·이웃집) → 캠프 버스 → 여름 캠프장(산장·사무소, 사당 오로라) → 파일섬 숲(파트너·쿠가몬) → 1번 길 → 행복의 마을(회복 센터·상점) → 해변 쉘몬(성실) → 2번 길(라이벌전) → 기어 사바나 · 우정의 신전 레오몬(우정) → 3번 길 → 장난감 마을 · 순수의 신전 퍼펫몬(순수)
- **포획**(디지몬 RPG 오마주): 가방의 디지바이스(싸움마다 3번, 유년기만) · 유년기 그물 · 성장기 그물, 체력이 적을수록 잘 잡힘, 성숙기 이상·우두머리는 못 잡음
- **포켓몬 금 구조**: 마을마다 회복 센터(에렉몬, PC 디지몬 보관함)·상점(비트), 문장 신전(체육관), 한쪽 턱, 떨어진 캡슐, 눈이 마주치면 덤비는 디지몬, 라이벌전, 지역별 레벨대
- **전투**: 금판 배치, 기술 4개·PP, 속성 상성(백신>바이러스>데이터>백신), 급소, 방어 단계, 교체, 가방, 도망, 레벨업, 진화(성장기→성숙기 Lv14, 완전체는 문장 + Lv30)
- **소리**: 지역별 배경 음악(MIDI 편곡), 효과음, 징글(회복·물건·레벨업·포획)
- **메뉴**: 도감 · 디지몬(능력 보기·순서 바꾸기) · 가방 · 주인공 정보(문장·비트) · 저장 / 이어서 하기
- 디지타마: 200걸음 뒤 부화

## 그림
- 디지몬 전투 그림은 `../art/<id>-f.png`(앞, 56칸 안) · `<id>-b.png`(뒤, 48칸 안)가 있으면 그것을, 없으면 임시 카드(속성 색 동그라미)를 쓴다. 지금 진짜 그림은 아구몬 앞모습 하나.
- 이미지 AI 원본 → `../tools/snapc.py` 로 4색 도트 → `../art/` → 롬 다시 만들기.
- 집·동네·캠프장·마을 지도: 이미지 AI 배경(`../art/src/bg/*_ai.png`)을 `tools/assets.py` 가 16×16 칸 조각(집·나무·텐트…)으로 잘라내고, `story.py` 에서 조각을 배치해 지도를 짠다. 색은 `tools/palfit.py fit2`(타일 묶기: 팔레트 7개 × 4색), 미리보기는 `build/maps/<지도>.png`.
- 숲·1번 길·해변 칸과 인물 걷기 그림은 아직 웹판 시험 그림을 자동 변환한 임시 그림 (A6·B 그림 오면 교체).

## 음악
- 소리 엔진 `src/music_drv.inc`: 포켓몬 금처럼 네모파1 멜로디 · 네모파2 화음 · 파형 베이스 · 잡음 드럼. 곡 자료와 함께 음악 뱅크 하나에 들어가고, 0번 뱅크는 VBL 마다 `music_update()` 만 부름.
- 곡: 제목 Butterfly · 집/동네/캠프장 「내일은 나의 바람이 분다」 · 디지털 월드 길 Target · 행복의 마을 Butterfly(피아노판) · 야생 전투 'digimon' 록 편곡 · 보스 Brave Heart · 진화 Brave Heart 전주 · 회복 징글(직접 작곡).
- MIDI(`music/src/*.mid`, 저장소에 안 올림) → `python3 tools/midi2gb.py` → `music/<곡>.json`(4채널 편곡) → 롬. 원곡 저작권은 권리자에게 있음 (팬 게임).

## 만들기
```
cd digimon/gbc
python3 tools/build.py          # → digimon.gbc
python3 tools/test_play.py      # PyBoy로 처음~쉘몬까지 자동 진행, build/shots/ 에 화면
python3 tools/test_route2.py    # 해변 → 2번 길 → 레오몬 (test_play 다음)
python3 tools/test_route3.py    # 사바나 → 3번 길 → 퍼펫몬 (test_route2 다음)
python3 tools/test_capture3.py  # 1번 길에서 유년기 포획
```
필요: GBDK-2020 4.4.0 (`/opt/gbdk`), Python3 + numpy + Pillow, Node(웹판 자료 내보내기), PyBoy(시험).

## 구조
| 파일 | 내용 |
|---|---|
| `story.py` | 지도·사건 스크립트 (웹판 story.js 를 옮김). `{kid}` `{baby}` 같은 변수, `{이/가}` 같은 조사 |
| `tools/build.py` | 웹판 자료 + story.py → C 데이터(글꼴·문자열·그림·지도·표) → GBDK 컴파일 |
| `tools/text.py` | 글자 모음·부호화·18칸 줄 나누기 |
| `tools/dsl.py` | 스크립트 명령 → 바이트코드 |
| `tools/gfx.py` | 2bpp 타일, 테두리·숫자·HP 막대 그리기 |
| `src/core.c` | 입력·뱅크·팔레트·한글 글상자·이름표 글자 (0번 뱅크) |
| `src/field.c` | 지도 그리기·스크롤·걷기·NPC·지도 이동·야생 만남 (0번 뱅크) |
| `src/script.c` `ui.c` `menu.c` | 스크립트 실행기, 메뉴 부품, 화면들 (2번 뱅크) |
| `src/battle.c` `mon.c` | 전투·진화·부화, 디지몬 계산 (1번 뱅크) |

## 지켜야 할 것 (어기면 멈춤)
- **0번 뱅크 밖 코드(1·2번)에서 `SWITCH_ROM` 금지** — 자기 자신이 사라져서 멈춘다. 다른 뱅크 자료는 `far_copy`·`far_vram`·`far_sprite`(0번 뱅크)로.
- 0번 뱅크 함수가 다른 뱅크 코드에서 불릴 수 있으면, 끝날 때 원래 뱅크로 돌려놓는다 (`field_enter` 등).
- 0번 뱅크가 꽉 차 간다(약 15.7KB/16KB). 새 기능은 1·2번 뱅크에 `BANKED` 로.
- VRAM 자리: 0번 칸 0~79 화면 부품, 80~151 글상자 글자, 152~255 필드 타일·이름표 글자 / 1번 칸 0~ 인물 OBJ(주인공 0~23, NPC 24~), 지도마다 `t1_base`(64 이상, NPC 그림 뒤)~191 필드 타일, 128~ 디지몬 그림, 192~255(필드 위 메뉴) 또는 214~255(전체 화면) 이름표 글자. 지도 한 장 타일은 최대 104 + (192 − t1_base)개.
- 한글은 대사에 쓰인 글자만 들어간다 (지금 약 500자). 한 줄 18칸 고정 폭.
