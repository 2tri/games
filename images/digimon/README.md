# 디지몬 그림 올리기 (집 PC → GitHub 웹, 토큰·git 설치 필요 없음)

그림은 **이 폴더(`images/digimon/`)에, 브랜치 `main`으로** 올립니다. 올린 뒤 디지몬 ROM 세션이 `main`을 가져가서 4색으로 다시 칠하고(`ingest.py`) ROM이 읽는 `digimon/art/`에 넣습니다. 직접 `digimon/art/`에 올리지 마세요.

## 파일 이름 규칙

| 그림 | 파일 이름 | 예 |
|---|---|---|
| 앞모습 | `<id>-f.png` | `agumon-f.png` |
| 뒷모습 | `<id>-b.png` | `agumon-b.png` |

- `<id>`는 **소문자 영문**, 단어 사이는 **하이픈(-)**: `agumon`, `whamon`, `v-mon`. 밑줄(`_`)·공백·한글·대문자 금지.
- 디지몬 한 마리당 **앞·뒤 2장**이 한 세트입니다. 한 장만 있어도 올려도 되지만, 빠진 쪽은 ROM 세션이 알려 줍니다.
- `<id>` 목록은 디지몬 주문 아티팩트의 이름을 그대로 씁니다.

## 집에서 올리는 순서

1. 제미나이로 그림을 뽑아 PNG로 다운로드합니다. 받은 파일 이름은 `Gemini_Generated_Image_…png`처럼 되어 있으니 **위 규칙대로 이름을 바꿉니다.**
2. 바탕화면 등에 폴더를 하나 만들어 이름을 바꾼 PNG만 모읍니다.
3. 브라우저로 `github.com/2tri/games` 를 열고 브랜치가 **main**인지 확인합니다(왼쪽 위 브랜치 선택 칸).
4. `images` → `digimon` 폴더로 들어갑니다.
5. **Add file → Upload files**를 누르고 모아 둔 PNG를 끌어다 놓습니다.
6. 아래쪽 **Commit changes**를 누르는데, 선택 항목은 **Commit directly to the `main` branch**인지 확인합니다.
7. 폴더 목록에 파일이 보이면 끝입니다. 디지몬 세션에 "올렸어"라고 알려 주세요.

한 번에 100장까지 올릴 수 있습니다. 파일 하나는 25MB 이하여야 합니다. 몇 마리씩 나눠 올려도 됩니다.

## 실수하기 쉬운 점 체크리스트

- [ ] **확장자 겹침**: 윈도우는 확장자를 숨깁니다. 이름을 바꿀 때 `agumon-f.png`로 쓰면 실제로 `agumon-f.png.png`가 되기도 합니다. 탐색기 **보기 → 표시 → 파일 확장명**을 켜고 확인하세요.
- [ ] **확장자는 소문자 `.png`**: `.PNG`, `.jpg`, `.webp`로 올리면 못 읽을 수 있습니다. 제미나이가 jpg/webp로 주면 PNG로 받거나 변환하세요.
- [ ] **대소문자·하이픈**: `Agumon-F.png`, `v_mon-f.png`는 틀린 이름입니다.
- [ ] **앞(-f)·뒤(-b) 뒤바뀜**: `-f`는 앞모습, `-b`는 뒤에서 본 모습입니다.
- [ ] **같은 이름을 다시 올리면 덮어씁니다**: 마음에 안 드는 그림을 다시 뽑았으면 같은 이름으로 다시 올리면 됩니다. 이전 그림은 GitHub 기록에 남습니다.
- [ ] **그림을 직접 줄이거나 색을 줄이지 마세요**: 4색 변환과 크기 맞춤은 ROM 세션이 합니다.
- [ ] **배경**: 제미나이가 준 그대로 올리세요(투명이든 흰색이든). 배경을 지워서 올리라는 규칙은 아직 정해지지 않았습니다. 불확실하므로 ROM 세션에서 정해지면 이 줄을 고칩니다.
- [ ] **반지 원정 파일과 섞지 마세요**: `images/` 바로 아래나 다른 폴더에 올리지 말고 반드시 `images/digimon/` 안에 올립니다.

## 안 보일 때

- `images/digimon` 폴더가 안 보이면 브랜치가 `main`이 아닌 것입니다. 브랜치를 `main`으로 바꿔서 다시 열어 보세요.
- 올렸는데 ROM 세션이 못 찾으면 파일 이름의 대소문자·하이픈·`.png.png`부터 확인하세요.
