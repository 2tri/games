# 반지 원정 그림 파일 이름표 (39장)

`ring/그림주문서.html`(주문서)의 순서와 1:1로 맞춘 표입니다. **파일 이름은 이 표 그대로, 확장자는 `.png`** 로 저장해서 이 `images/` 폴더에 올리세요.

- 주문서(복사 버튼으로 제미나이 문장 복사): https://2tri.github.io/games/ring/그림주문서.html
- 번호가 곧 중요도 순서입니다. 앞 번호부터 만들면 됩니다. 다 못 만들어도 올린 것까지만 게임에 넣습니다.
- 한 파일에 여러 명이 들어 있는 시트(예: 호빗 마을 사람 ×3)도 **파일은 한 장**입니다.
- 제미나이가 `.jpg`·`.webp`로 줘도 괜찮습니다. 이름 앞부분(번호_이름)만 맞으면 확장자는 달라도 받아서 처리합니다.
- 제미나이 방은 3개(① 배경·타일 / ② 걷기 / ③ 전투·아이콘·일러스트)로 나눠야 그림체가 맞습니다.
