## 고칠 것
1. **스타팅 볼 이름 불일치** — 볼을 고르면 그림과 글이 다름(「그 볼에는 얼음 속성의 파피몬…」). 원인: 고르기 대사 msg189 #1(풀 칸)/#3(물 칸)을 v1 이 반대로 넣었고, 「그 볼에는 ○ 속성의 …」 줄은 디지골드 원래 스타팅 그대로. v1: 풀 칸=파닥몬(277), 불꽃=아구몬(252), 물=케라몬.
2. **라이벌 차례가 엉뚱함** — 라이벌 고르는 스크립트 비교 값이 287·252(디지골드), 마지막 라이벌(파일 819)은 152·155 그대로. v2 `hg_event.py` 수정(파일 7·23·96·110·111·819·850·866, 11곳)을 v1 칸으로. v1 4차 라이벌 상대 맞춤 디지몬도 어긋남(풀 상대인데 릴리몬 등).

4. **기술 이름이 전투에서 다름** — 「꼬마불꽃」이 전투에서 「사념의박치기」. 전투 글 msg 3 에 옛 이름(846줄). v2 `hg2.py` msg3 다시 쓰기 + 필살기 설명(msg 742) + `rom_check.py` 대조 검사. 불일치 0 확인.
