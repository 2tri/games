# 실제 진행 순서대로 확인한 기록 (스크립트 실행 순서가 아니라 직접 플레이한 순서)
1. 새 게임 → 방(2층)에서 시작 → 계단으로 1층 (엄마 자동 대화: 트레이너카드·리포트·가방·설정 메뉴가 열림)

4. 서쪽(29번도로) 출구 (676,396)에 서면 친구가 「잠깐 기다려! 너 디지몬기어는? … 엄마한테 물어보렴」 하며 막음 (디지바이스를 아직 안 받은 상태)

7. 연구소를 나올 때 조수가 도구를 줌(상처약×5, 디지볼×10 가방에서 확인).

9. 할아버지 집에서 「이상한알」(대발견의 알)을 받음 + 도감 메뉴가 열림(자동 연출).
10. 집을 나서면 공박사 전화(큰 일이다!)·엄마 전화가 자동으로 걸림 → 29번도로 (600,398) 부근에서 라이벌 전투(1차).
11. 연구소(지도61)로 돌아가면 경찰·소동 장면 → 라이벌 이름 입력 화면 → 알 건넴 (대사 약 70쪽).
12. 31번도로(지도35) 서쪽 (518,269)에서 한 걸음 더 서쪽으로 가야 관문(지도97)이 열림 → 관문 서쪽 끝 (1,7)에서 한 걸음 더 → 전망산 마을(지도73) (511,269).
13. 수수께끼의 탑(지도110→155→156 꼭대기): 장로(12,9)와 전투 → 「플래시」기술머신 + 학습장치(경험 나눠주는 도구) 받음. 밟는칸(13,17)에서 라이벌이 장로에게 시비(이벤트).
14. 전망산 수련장(지도135): 입구 안내원 → 트레이너 2명 → 소라(15,4) 전투. 이기면 사랑의 문장(리그 배지 칸).
15. 전망산 프렌들리숍(지도157)의 조수 리키(6,8)에게 말 걸면 「알」을 맡김(파티 2번째 칸에 「알」). 수련장 클리어 뒤 공박사 전화(「알에 대해 알게 된 것…프렌들리숍으로」)가 자동으로 걸림.
16. 곤충 마을(지도74) 우물(지도177, 랜스 (27,3)): 랜스 이기면 어둠의돌 ×3 (가방 도구칸에서 확인 ✔). 이긴 뒤 커트의 집(지도164)으로 이어짐.
17. 곤충 마을 수련장(지도180) 한솔 — 거미줄 구조라 걸어서 못 나옴(자동 길찾기 한계). 이김.
18. 장난감 마을 수련장(지도137) 미나 이김.
19. 에코루티(지도78) 가트몬 수련장(지도80): 처음 들어가면 「가트몬은 불탄탑에 갔다」며 쫓겨남(변수 0x4079=1). 불탄탑(지도7)→지하(지도217)의 세 성수 장면(0x4079=2)을 보고 나면 가트몬이 수련장에 돌아와 싸울 수 있음 ✔(실제 전투 확인). 수련장 바닥은 함정 칸(스크립트3 밟는칸) 피해서 걸어야 함.
20. 불탄탑 1층 (22,19) 부근에서 라이벌 전투(3차) 발생.
21. [발견] 연구소 이벤트(「벌써 문장 N개 …마스터디지볼 … 전통무용수들이 예술극장에서 기다린다」, 변수 0x4108==8 일 때 연구소에 들어가면 자동)는 0x4108=8 이 되는 곳(지도288 = 용의 장로 시험 쪽, 파일112)과 연결 → 무녀 5명·암흑단 구출(지도86)은 그 뒤에 열리는 구조로 보임. 공략서 6장 순서(무녀 → 가트몬)와 다름 — 확인 중.
22. [공략서 오류 발견] 가무연장(지도86): 파도타기는 「무녀 다섯을 이겨서」가 아니라 **가무연장 안 암흑단 조직원(7,6)과 싸워 이긴 뒤 무대 아래 (3,8)·(11,8) 칸을 밟으면 할아버지가 「비전머신03」(파도타기)을 줌**(실제 확인 ✔). 무녀 다섯 명은 그 뒤(연구소 장면·용의 장로 시험 이후) 열리는 구조.
23. [버그 발견] 바위산 마을 수련장 레오몬(지도139): 대사는 「용기의 문장이다 사랑의 디지멘탈도 주마」인데 스크립트가 실제로 주는 도구는 기술머신(0x166)+격투타입의 석판(0x12f)뿐 — **사랑의 디지멘탈이 1부 어디서도 안 나옴**(롬 전체 검색: 사랑의 디지멘탈 지급은 지도312 한 곳뿐). → 호크몬→할세몬 진화 불가. 수정 필요: 레오몬 스크립트(파일877 @0x14e)의 도구 0x12f → 0x50(사랑의 디지멘탈).
24. 레오몬 수련장은 폭포 퍼즐을 풀어야 말이 걸림(변수 0x4000==0 이면 「수행에 열중하여 눈치채지 못한다」). 시험은 그 확인만 건너뜀(원작 퍼즐 그대로).
25. [확정] 체육관 보상 점검(롬 스크립트에서 실제 지급 도구): 소라(TM+석판) 한솔(TM+석판) 미나(기력의조각×3) 가트몬(희망의 디지멘탈) 레오몬(**TM31+격투 석판 — 사랑의 디지멘탈 없음 ✗**) 안드로몬(태그) 정석(지식의 디지멘탈) 리키(궁극의 문장×2). 원인: 설계표(NDS_선물도구.tsv)가 레오몬 원래 도구를 TM01(328)로 적었는데 실제는 TM31(358).
26. 안드로몬(규리) 수련장(지도138)은 처음엔 비어 있음(숨김). 순서: 등대 꼭대기(지도225) 안드로몬(7,8)에게 말 → 「바위산 마을의 약이 필요」(변수0x40a5=1) → 바위산 마을 약국(지도233, 5,5) 「비전신약」(중요한 물건) 받음 ✔ → 등대 꼭대기 안드로몬에게 말하면 약을 건네고 빛나리가 나음 ✔ → 수련장으로 돌아감.
27. [원칙] 목적 = 내가 착각한 부분을 찾아 **롬을 설계대로 고치는 것**(공략서를 롬에 맞춰 다시 쓰는 게 아님). 어긋남 목록: ①사랑의 디지멘탈(레오몬) 미지급 → 롬 수정 ②파도타기 출처(공략서만 틀림) ③호크몬 = 헤매는 숲에서 도망친 호크몬을 잡는 이벤트(숯 전문가에게 돌려주면 풀베기+숯, 지도117/163) — 「바위산 마을 선물」은 롬에 없음 ④브이몬·쿠가몬 출처는 아직 확인 필요.
28. [해소] 얼음나라(지도87)에서 뜬 「한참 검은 화면」은 시험 방식(지도199에서 워프 스크립트로 이동) 때문에 생긴 가짜였음. 정상 상태(4134==4)에서 들어가면 공박사 전화 → 변수 0x4077=2, 0x4134=5 가 자동으로 설정됨(진행 정상).
