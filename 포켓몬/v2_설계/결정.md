# 디지몬골드 v2 설계 결정 (2026-10-19, 사용자와 정함)

- v1 은 `digimongold-v1` 태그로 완성본 보관. v2 는 새로 짬.
- **스토리**: 파워디지몬(어드벤처 02) 스토리·인물 뺌. 1부 = 디지몬 어드벤처 1기(데블몬 → 에테몬 → 묘티스몬/베놈묘티스몬 → 다크마스터즈 4천왕 → 아포카리몬). 2부 = 극장판 「우리들의 워게임」(쿠라몬 → 디아블로몬, 오메가몬)을 늘린 이야기.
- **주인공**: 태일 유지(나리 포함 v1 그림 유지).
- **로스터**: v1 디지몬 191종 그대로(아래 제외 반영). 새 종 추가 안 함(파워디지몬 조연 9종도 안 넣음). 진화 줄만 다듬음.
  - 뺌: 유아기Ⅰ(깜몬·푸니몬 등) 전부, 테이머즈 첫 등장 디지몬 전부, 도트·색만 다름·모드 변형판, 로열나이츠·칠대마왕·올림포스12신·프론티어 삼대천사.
  - 변형판 중 남김: 블랙워가루몬, 황제파이터, 황제팔라딘, 다크그레몬.
  - 사성수(청룡·백호·주작·현무): 엔딩 뒤 전설 디지몬.
- **진화 단계**: 알 → 유년기 → 성장기 → 성숙기 → 완전체 → 궁극체. 유년기는 알 모양으로 따라다님, 성장기부터 진짜 걷기 그림.
- **이름**: 공식 한국어 도감(digimon.net/reference_ko) 이름 기준(이블몬, 잎새몬 등). 사용자가 다르게 기억하는 것만 예외.
- **어둠·비주류 계열**: 성장기부터 궁극체까지 끝까지 키울 수 있는 줄을 충분히(피코데블몬·가지몬·케라몬·데블드라몬 줄 등).
- **게임 규칙**: 포켓몬 체계를 뼈대로 유지, 디지몬 느낌은 얹는 방식. 속성 상성(백신>바이러스>데이터>백신 ×1.2/×0.8) 유지.
- 자료: species.tsv(속성·태그·제외 제안), evo_edges.tsv(진화 연결, Dawn/Dusk 진화표 + v1), lines_final.tsv(진화 줄), ko_names.tsv(공식 한국어 이름).

## 10/19 추가 결정
- 테이머즈 첫 등장이지만 예외로 남김: **메탈티라몬**(아구몬 어둠 줄 → 파워드라몬으로 가는 길), **호우오몬**(피요몬 계열 궁극체).
- **스타팅 = 아구몬 / 팔몬 / 베타몬** (타입 불꽃·풀·물 삼각과 속성 백신·데이터·바이러스 삼각이 엇갈림). 파닥몬·케라몬은 스타팅에서 뺌.
- **알 선물 = 토코몬(→ 파닥몬)**. 플롯트몬(→ 가트몬)은 이야기 이벤트·야생으로.
- **라이벌 매튜 = 파피몬 고정**, 내 스타팅에 맞춰 상성 디지몬 하나만 바꿈.
- **유년기**: 극초반에만 가볍게. 코로몬·뿔몬·어니몬·모티몬·시드몬·둥실몬·야옹몬·츠메몬·퍼그몬 + 토코몬(알). Lv8~10에 성장기로. 그 밖의 야생은 성장기부터.
- 진화 줄: 모든 종을 궁극체까지 잇지 않음. 공식 근거가 있거나 자연스러운 것만.
- 아머 진화 = 디지멘탈 아이템, 조그레스 = 짝 디지몬과 함께 진화(오메가몬은 2부 이야기에서 처음 보여 줌).
