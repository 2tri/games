# NDS 롬 클라우드 작업 안내 (2026-10-18, 「GitHub 저장소 NDS 롬 파일 설정」 세션 → 롬 수정 세션)

로컬 PC가 없어도 **클라우드 Claude Code 세션에서 롬을 받아 → 수정하고 → 브라우저에서 바로 실행**할 수 있다. 아래 내용은 모두 2026-10-18 클라우드 세션에서 직접 확인한 것이다.

## 1. 롬 받기 (확인됨)
- 저장소: `2tri/games`, LFS 추적: `*.nds` (`.gitattributes`)
- 원본 롬: `포켓몬/1_폰에 넣을 파일/디지몬골드 v1.6 (이지+노래 1016 밤).nds`
  - 128MB (134,217,728 B), sha256 `57284e28543b4ab9…` (LFS oid 와 일치)
  - 롬 헤더: `POKEMON HG` / `IPKK` → **하트골드 한국판 기반**, 내부 파일 511개
- 클론하면 포인터(134바이트)만 있음. 실제 파일 받기:
  ```sh
  git lfs pull --include="포켓몬/**"          # 클라우드 세션에서 동작 확인
  # 또는 (git 없이)
  curl -L -o rom.nds "https://media.githubusercontent.com/media/2tri/games/main/<URL 인코딩된 경로>"
  ```

## 2. 롬 열기·수정 (Python)
- `pip install ndspy` → 바로 열림 (확인됨)
  ```python
  import ndspy.rom
  rom = ndspy.rom.NintendoDSRom.fromFile('…/디지몬골드 v1.6 (이지+노래 1016 밤).nds')
  print(rom.filenames)            # 파일 트리 (a/0/0/… = 하트골드 NARC 구조)
  data = rom.getFileByName('a/0/0/0')
  rom.setFileByName('a/0/0/0', new_bytes)
  rom.saveToFile('수정본.nds')
  ```
- NARC 안쪽은 `ndspy.narc`, 그래픽은 `ndspy` 의 texture/graphics 모듈 또는 별도 도구 필요 (그림 교체 방식은 **아직 미검증**).

## 3. 수정본 실행 확인 (브라우저, 설치 없음)
- 웹 플레이어: `nds/index.html` (EmulatorJS 4.2.3, melonDS·DeSmuME 2015)
  - 주소: `https://2tri.github.io/games/nds/` — main 에 머지돼야 Pages 에 올라감
  - 다른 롬: `https://2tri.github.io/games/nds/?rom=폴더/파일.nds` (main 브랜치의 LFS 파일을 받음)
  - 폰에 있는 파일 직접: 「내 기기 파일로 열기」 버튼
  - 한 번 받은 롬은 기기에 저장(IndexedDB). **같은 경로에 수정본을 올리면 「저장된 롬 지우기」 후 다시 받아야 새 버전**이 실행됨 → 수정본은 파일명에 버전을 붙여 다른 경로로 올리는 것을 권장
- 클라우드 세션 안에서 자동 확인 (사람 없이 화면 캡처):
  - Playwright + Chromium 은 기본 설치됨. 로컬 서버: `python3 -m http.server 8765` (저장소 루트)
  - **주의**: 프록시 때문에 `localhost`/`127.0.0.1` 로 열면 405 오류 → `hostname -I` 의 IP(예: `192.0.2.2`)로 열고 Playwright `proxy.bypass` 에 그 IP 지정
  - `?rom=` 은 GitHub(main)에서 받으므로, 아직 푸시 안 한 로컬 수정본은 페이지의 파일 열기(`setInputFiles('#file', 경로)`)로 넣으면 됨
  - 확인 결과: 128MB 다운로드 ~10초, 타이틀 「디지몬 어드벤처 골드」 화면까지 정상

## 4. 수정본 올리기
- `.nds` 는 자동으로 LFS 로 올라감 (`git add` → `git commit` → `git push`)
- LFS 용량: GitHub 무료 계정은 저장·전송량 한도가 있음 → 128MB 수정본을 자주 올리면 금방 참. 중간본은 올리지 말고 확정본만 올릴 것 (한도 수치는 **불확실함**, GitHub 설정 → Billing 에서 확인)
- 클라우드 세션에서 LFS **푸시**는 아직 시험하지 않음 (**불확실함** — 받기는 확인됨)
- 저장소가 공개라 올린 롬은 누구나 받을 수 있음
