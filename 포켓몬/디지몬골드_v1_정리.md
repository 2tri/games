# 디지몬골드 v1 — 완성본 정리 (2026-10-19)

하트골드(한국판 NDS)를 디지몬으로 바꾼 롬핵의 **첫 완성본**입니다. 이 판은 그대로 보관하고, 다음 판(v2)은 「어드벤처만으로 스토리 + 시리즈 상관없이 디지몬 출현」으로 새로 짭니다.

## 1. 하는 법
- **폰 브라우저**: https://2tri.github.io/games/nds/ → 「시작」 (아이폰은 DeSmuME 2015 코어가 자동 선택됨)
- **델타 등 에뮬레이터**: 롬 파일을 받아서 엶 → `포켓몬/1_폰에 넣을 파일/디지몬골드 최신 (이지+노래).nds`
- git 태그 `digimongold-v1` 이 이 판의 소스·표·도구 상태입니다.

## 2. v1 내용 요약
- 1부(성도 = 파일섬): 디지몬 어드벤처·02 인물과 디지몬, 수련장 8곳 → 4천왕(다크마스터즈) → 챔피언(아포카리몬)
- 2부(관동): 02 인물 중심 (v2에서 어드벤처 극장판 「우리들의 워게임」 중심으로 다시 짤 예정)
- 스타팅: 파닥몬·아구몬·케라몬 (v2에서 다시 정함)
- 디지몬 약 190종, 노래 131곡, 난이도: 이지판 기준(하드판은 도구로 만들 수 있음)
