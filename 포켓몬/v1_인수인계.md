# 디지몬 골드 v1 — 인수인계 (PC 원격 세션용)

최신 기준: 브랜치 `claude/digimongold-v1-fixes`. 사용자는 폰 Claude 앱 Code 탭에서 PC 원격 세션으로 이어서 작업함.

## 1. 지금 상태
- 빌드는 **이지+노래 한 종만** 만든다: `포켓몬/1_폰에 넣을 파일/디지몬골드 최신 (이지+노래).nds` (Git LFS, 약 128MB).
- 사용자는 Delta(폰)로 플레이 → **롬이 바뀌면 새 게임**으로 시작해야 한다.
- 최신 수정 기록: `포켓몬/v1_수정_기록.md` §24 (v1.4, 10/27). 이전 §23 (v1.3). 직접 플레이로 확인한 순서/발견: `포켓몬/v1_검증_흐름기록.md`.
- 1부 가이드 원본(생성기·자료): `포켓몬/가이드_원본/` (`gen.py`, `chapters_v13.py`, `template.html`). 게시본: https://claude.ai/artifact/PjtYyHWZhwFhagFRoUGVoY (v6). `gen.py` 안의 경로는 클라우드 작업 폴더 기준이라 PC에서 쓰려면 경로를 손봐야 함(불확실함: 안 돌려 봄).

## 2. 빌드 체인
- `_run_linux_d.sh` → 단계별 스크립트 실행, 마지막 `수정판_시험/inject_story_fix.py` (v1.3 수정: 브이몬·호크몬 선물, 레오몬 디지멘탈 위치, 청룡몬 Lv60, 옛 기술머신 설명 교체, 「그대로:」 이름표 등. 여러 번 돌려도 같은 결과).
- 검사: `rom_check.py` (메시지 개수 변화 허용 목록 `EXPECT_ADD = {383: 2, 575: 2}`).
- 이 빌드는 리눅스(bash)·python3 전제. **PC가 Windows라 그대로는 못 돌릴 수 있음(불확실함)** — 롬을 새로 빌드하려면 클라우드 세션이 편하고, PC에서는 문서·표 수정과 git 작업 위주로.
- 에뮬 시험: PC(Windows)에도 py-desmume 가 깔려 있어 됨. 도구 `수정판_시험/에뮬검사/pc/` (README 참고: 방 스크립트를 순간이동 명령으로 바꾼 시험 롬 + 자동 대화/전투).

## 3. 남은 일 (1부)
확인 못 한 것:
- 어둠의 4천왕 4번째 방(피에몬)·챔피언(아포카리몬)·배표·명예의 전당
- 리키 체육관 안 걷기(함정 칸)
- 쿠가몬·붉은 메가시드라몬·돌핀몬 실제 포획
- 라디오 타워 지하 라이벌(매튜 4차), 절구산/켄터스몬 선물, 선물 후 디지멘탈 진화 장면 (스크립트로만 확인)
- 라디오 타워 꼭대기가 카드키 없이도 가지는지
- 검은 톱니 아지트 보상은 롬에 없음(상점이 배지 7개부터 판매)

## 3-1. 2부 — v1.5 완료 (10/27): 카이저 정우 전투 + 대사 끊김 128줄 + v15 수정, 폰 롬 교체. 자세한 건 `v1_수정_기록.md` §25
- 트레이너 사람의 스크립트 번호 = 2999 + 트레이너 번호. 트레이너 대사표는 1717칸을 넘기면 못 읽음 → 새 트레이너 대사는 안 쓰는 칸(541 애호가클럽 무광 3줄이 아직 빔)을 돌려쓸 것.
- 대사 줄바꿈 규칙: 쪽마다 「첫 줄 \n 둘째 줄 \f 셋째 줄 \f …」, 새 쪽은 \r. 둘째 줄 뒤 \n 금지(셋째 줄로 넘쳐 끊김). 빌드 마지막 `lb` 단계가 자동으로 고침.
- 10/27 소넷으로 이어서 확인한 것(에뮬): ① 정우는 관문(지도299, 「증표 여덟 개」 대사) 출구 바로 옆이라 수호자 8명 뒤에만 만남 ② 마일도 최종전 대사 3종+끝맺음 롬에 없던 것을 `inject_mildo.py`(빌드 `ml`)로 채움, 전·승·패 전부 확인(§25-4) ③ 2부 연구소(지도505): 들어가면 겐나이 장면이 바로 시작 → 책상 (7~9,3) 조사 칸에서 공 고르기(「곤충 디지몬 스팅몬으로 하겠느냐?」 예 → 「오박사로부터 스팅몬을 받았다!」 → 별명) 동작. 가트몬·스팅몬 확인, 엔젤우몬은 안 봄 ④ 나리 첫 등장(글 531:0)·산해 배 안 대사(254:9)·정우 첫 대면(515:0) 롬에 있음.
- **사용자 결정이 필요한 것: 박사 이름이 섞여 있음.** 용어표는 공박사·오박사 둘 다 「겐나이(문맥)」인데 롬에는 「공박사」 49줄(1부 시작의 마을)·「오박사」 73줄(2부 겐나이 마을)이 남아 있고, 화자 이름표만 「겐나이:」(예: 글 372:8 「겐나이: … 내가 디지몬 연구가인 오박사다」). 1부=공박사·2부=오박사로 두는 건지, 전부 겐나이로 통일하는 건지 정해야 함.
- 남은 2부 점검(소넷으로 가능): 예지 수호자 외출 장면, 엔젤우몬 스타팅 공, 공략집 2부.

## 4. 작업 규칙
- 근거 기반, 추측은 「불확실함」 표시, 짧게. 사용자는 PCB 제조 기술팀 엔지니어(게임은 취미), 쉬운 한국어 선호.
- PR은 사용자가 요청할 때만. 롬을 바꾸면 반드시 한 빌드로 모아 한 번만 교체(사용자가 새 게임을 매번 해야 하므로).
- 태그 `digimongold-v1.1`은 만들지 못했음(사용자가 직접).
