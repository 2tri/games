# 디지몬 골드 v1 — 인수인계 (PC 원격 세션용)

최신 기준: 브랜치 `claude/digimongold-v1-fixes`. 사용자는 폰 Claude 앱 Code 탭에서 PC 원격 세션으로 이어서 작업함.

## 1. 지금 상태
- 빌드는 **이지+노래 한 종만** 만든다: `포켓몬/1_폰에 넣을 파일/디지몬골드 최신 (이지+노래).nds` (Git LFS, 약 128MB).
- 사용자는 Delta(폰)로 플레이 → **롬이 바뀌면 새 게임**으로 시작해야 한다.
- 최신 수정 기록: `포켓몬/v1_수정_기록.md` §24 (v1.4, 10/27). 이전 §23 (v1.3). 직접 플레이로 확인한 순서/발견: `포켓몬/v1_검증_흐름기록.md`.
- 1부 가이드 원본(생성기·자료): `포켓몬/가이드_원본/` (`gen.py`, `chapters_v13.py`, `template.html`). 게시본: https://claude.ai/artifact/PjtYyHWZhwFhagFRoUGVoY (v6). `gen.py` 안의 경로는 클라우드 작업 폴더 기준이라 PC에서 쓰려면 경로를 손봐야 함(불확실함: 안 돌려 봄).

## 2. 빌드 체인
- `_run_linux_d.sh` → 단계별 스크립트 실행, 마지막 `수정판_시험/inject_story_fix.py` (v1.3 수정: 브이몬·호크몬 선물, 레오몬 디지멘탈 위치, 청룡몬 Lv60, 옛 기술머신 설명 교체, 「그대로:」 이름표 등. 여러 번 돌려도 같은 결과).
- 검사: `rom_check.py` (메시지 개수 변화 허용 목록 `EXPECT_ADD = {383: 2, 575: 2}`).
- 이 빌드는 리눅스(bash)·python3 전제. **PC가 Windows라 그대로는 못 돌릴 수 있음(불확실함)** — 롬을 새로 빌드하려면 클라우드 세션이 편하고, PC에서는 문서·표 수정과 git 작업 위주로.
- 에뮬 시험: PC(Windows)에도 py-desmume 가 깔려 있어 됨. 도구 `수정판_시험/에뮬검사/pc/` (README 참고: 방 스크립트를 순간이동 명령으로 바꾼 시험 롬 + 자동 대화/전투).

## 3. 남은 일 (1부) — 10/27 정정: 아래 옛 목록 대부분은 `v1_검증_흐름기록.md` 44~63번에서 이미 확인됨
- 확인됨(에뮬 실제): 4천왕 4번째·챔피언·명예의 전당·배표, 쿠가몬·돌핀몬·메가시드라몬 포획, 선물(켄터스몬·아르마몬·호크몬·브이몬), 디지멘탈 진화 장면, 매튜 4차, 카드키 없이 꼭대기 못 감
- 진짜 남은 1부: 리키 수련장(지도141) 용암 퍼즐 직접 통과(원본 v1.6과 같아 위험 낮음), 검은 톱니 아지트 보상은 롬에 없음(상점이 배지 7개부터 판매)
- **1부→2부 이음매(10/27 에뮬)**: 겐나이에게 배표(플래그 0x964) → 톱니공장 항구(지도240)에서 선원에게 **남쪽을 보고** 말 걸기(북쪽을 보면 다른 분기) → 티켓 확인 → 선원이 남쪽 2칸 걸려 보냄 → 남쪽 문으로 나가 부두를 따라 가면 큰 배 입구 선원이 「네가 마지막 손님이로구나」 → 출항·배 안 연출 정상. 첫 항해는 요일 무관(VAR_SCENE_SS_AQUA<7), 이후 월·금만(원작 규칙). 항구 스크립트(152)·배 복도 스크립트(156)는 원본 하트골드와 바이트 단위로 같음.
- **미확인·의심**: 설계 장면 230(배 안 산해 「너, 신대륙은 처음이지?」, 글 254:9)은 글만 있고 나오는 곳을 못 찾음 — 스크립트 156은 원본 그대로이고 배 복도(지도307)의 숨은 인물(obj3, 숨김 플래그 533)을 켜는 스크립트가 어디에도 없음. 배 안에서 산해를 만나는 장면이 실제로 안 나올 가능성이 큼(복도 끝까지 걸어 확인하다 시험이 길어져 중단). 이어서 확인할 것.

- PR은 사용자가 요청할 때만. 롬을 바꾸면 반드시 한 빌드로 모아 한 번만 교체(사용자가 새 게임을 매번 해야 하므로).
